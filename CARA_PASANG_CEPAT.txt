 Paket ini untuk Bapak yang SUDAH pernah memasang RTS_PANEL_PUTARAN_18D.zip.

 PUTARAN 18G - EMPAT PERUBAHAN UTAMA:
   1. RUTE PLAN: garis rute OTOMATIS DIHILANGKAN. Yang tampil hanya TITIK
      toko BERNOMOR sesuai urutan; garis dibuat sendiri lewat ikon PENSIL.
      Urutan kunjungan dapat DIGESER (tekan lama lalu tarik) dan dapat
      DISALIN sebagai TEKS lewat tombol COPY URUTAN (TEKS) untuk dilaporkan
      ke ASS / Admin.
   2. MENU PRO BARU "PROGRAM" dengan dua sub-menu: INTRODEAL dan BD (produk
      launching PT Wismilak). Produk dapat diambil dari Menu Barang Bawaan
      atau disinkron dari server; setiap produk menampilkan berapa customer
      yang sudah membelinya (dari nota di HP).
   3. KASIR, PIUTANG, PROGRAM: pemilih toko mengurutkan toko dari yang
      TERDEKAT dengan posisi HP (2 baris teratas = toko terdekat).
   4. WSS & SMST: daftar customer TIDAK dipotong menurut Sales District
      (keduanya ada di setiap district).

 Paket lengkap putaran ini: RTS_PANEL_PUTARAN_18G.zip.

 ISI MENU CCTV ONLINE:
   - TIGA TAMPILAN seperti halaman resmi ATCS Dishub: DAFTAR, GRID KAMERA
     (kotak bergambar + tombol Play), dan PETA (seluruh kamera sebagai titik);
   - tombol PERIKSA -> lencana SIAP / TIDAK TERSEDIA (berlaku 10 menit);
   - kotak pencarian + urutan Nama / Nomor / TERDEKAT (dari posisi HP);
   - video HLS diputar langsung di dalam aplikasi + layar penuh + tombol peta;
   - tombol HEMAT KUOTA untuk mematikan gambar kamera pada tampilan Grid;
   - khusus AKUN PRO (dikunci di aplikasi + diperiksa ulang di server).

 LANGKAH 1 - DI HOSTING (cPanel)
 -------------------------------
   1. Buka File Manager -> public_html -> folder api
   2. Unggah  api/cctv.php   (pilih TIMPA bila ditanya)
   3. Bila belum ada, unggah juga api_bootstrap.php dan kolom.php ke folder api
   4. Pastikan  public_html/periksa_cctv.php  dan
      public_html/data/cctv_medan.json  sudah ada dari Tahap 1
   5. Tidak ada perubahan database pada tahap ini.

 LANGKAH 2 - DI KOMPUTER (proyek Flutter D:\Project\rts_panel_app)
 ----------------------------------------------------------------
   1. Ekstrak paket ini ke mana saja (misalnya Desktop), pilih TIMPA semua.
   2. Klik kanan  LANGKAH1_PASANG_SEMUA.ps1  ->  Run with PowerShell
      (skrip menyalin main.dart, cctv.dart, pubspec.yaml ke proyek Bapak,
       berkas lama dicadangkan dulu)
   3. Buka terminal di folder proyek, jalankan berurutan:
          flutter clean
          flutter pub get
          flutter analyze
          flutter build apk --release
   4. Bila flutter pub get meminta Flutter yang lebih baru:
          flutter upgrade     lalu     flutter pub get

 LANGKAH 3 - DI HP
 -----------------
   1. Pasang APK baru dengan cara MENIMPA.
      JANGAN hapus aplikasi lama (data Kasir & STRUK POM di HP tetap aman).
   2. Buka aplikasi -> Menu PRO -> CCTV Online.
   3. Kalau muncul "Daftar kamera tidak dapat diambil", tekan ikon awan
      (SEGARKAN) di kanan atas - atau buka di peramban:
          https://<alamat-situs>/periksa_cctv.php?ambil=1
   4. Tekan tombol PERIKSA supaya muncul lencana SIAP / TIDAK TERSEDIA
      (seperti tombol READY pada situs Dishub).

 PEMERIKSAAN SESUDAH PASANG
 --------------------------
   Buka di peramban:  https://<alamat-situs>/periksa_cctv.php
       harus tertulis 111 kamera dan ada contoh tautan HIDUP.
   Di komputer: jalankan .\PERIKSA_KODE_APLIKASI.ps1
       harus tertulis kode aplikasi  RTS-2026-10-05-18G.
