 RTS PANEL BY BENE - PUTARAN 18I
 (MENU "PROGRAM" KEMBALI SATU SAJA: LIST CUSTOMER YANG MENGIKUTI PROGRAM +
  TOMBOL MELAYANG INPUT PROGRAM; PROGRAM BISA DIBUAT SENDIRI; PETA TETAP;
  TOMBOL SINKRON DI DALAM MENU DIHAPUS)
 CARA PASANG CEPAT  -  5 Oktober 2026
==============================================================================

 Paket ini untuk Bapak yang SUDAH pernah memasang RTS_PANEL_PUTARAN_18H.zip.
 Isinya hanya berkas yang BARU atau BERUBAH untuk perbaikan menu "Program".

 ENAM PERUBAHAN PUTARAN 18I
 --------------------------
   1. TOMBOL PROGRAM DIJADIKAN SATU SAJA:
      "Program Introdeal", "Program BD", dan "Input Program" DIHAPUS.
      Sekarang hanya ada satu tombol: PROGRAM
      (keterangan: List customer & input program).
   2. ISI MENU PROGRAM: LIST CUSTOMER YANG MENGIKUTI PROGRAM.
      Tiap baris = satu customer + nama toko + ID + program yang diikuti +
      jumlah catatan + berapa yang belum dikirim. Ketuk barisnya untuk
      melihat riwayat program customer itu.
   3. PROGRAM: INTRODEAL (paket 2+1 dan 1+1), BD, dan LAIN-LAIN.
      Sales dapat membuat PROGRAM SENDIRI (tombol PROGRAM BARU), dan
      menentukan apakah program itu memakai paket atau tidak.
   4. TOMBOL MELAYANG "INPUT PROGRAM" (kanan bawah, warna merah):
      ditekan -> muncul LIST CUSTOMER (urut dari yang terdekat) ->
      pilih programnya -> pilih produk dari Barang Bawaan -> SIMPAN DI HP.
      Bisa dikerjakan TANPA INTERNET.
   5. PETA TETAP ADA: ikon peta di kanan atas halaman Program, berisi peta
      OpenStreetMap + penyaring PROGRAM, KUNJUNGAN (sudah/belum), dan HARI.
   6. TOMBOL SINKRON DI DALAM MENU DIHAPUS (SINKRON PRODUK di Barang Bawaan,
      SEGARKAN di Peta Customer & Rute Plan, SINKRON ONLINE di Program).
      Sinkronisasi sekarang terpusat pada menu SINKRONISASI di menu utama
      (tombol SINKRONKAN SEKARANG). Tombol itu sekarang sekaligus menarik
      status akun, PRODUK (SKU & harga), dan DAFTAR TOKO.

 LANGKAH 1 - DI HOSTING (cPanel)
 -------------------------------
   1. Buka File Manager -> public_html -> folder api
   2. Unggah  api/program.php  (pilih TIMPA bila ditanya)
   3. Bila tabel program belum ada: buka phpMyAdmin -> database Bapak ->
      menu SQL -> tempel SELURUH isi RTS_PANEL_PROGRAM.sql -> tekan GO.
      Aman dijalankan berkali-kali; tidak ada data lama yang dihapus.
   4. Tidak ada berkas hosting lain yang berubah pada putaran ini.

 LANGKAH 2 - DI KOMPUTER (proyek Flutter D:\Project\rts_panel_app)
 ----------------------------------------------------------------
   1. Ekstrak paket ini ke mana saja (misalnya Desktop), pilih TIMPA semua.
   2. Klik kanan  LANGKAH1_PASANG_SEMUA.ps1  ->  Run with PowerShell
   3. Buka terminal di folder proyek, jalankan berurutan:
          flutter clean
          flutter pub get
          flutter analyze
          flutter build apk --release

 LANGKAH 3 - DI HP
 -----------------
   1. Pasang APK baru dengan cara MENIMPA. JANGAN hapus aplikasi lama
      (data Kasir, STRUK POM, dan catatan program di HP tetap aman).
   2. Buka aplikasi -> MENU PRO -> sekarang hanya ada satu tombol: PROGRAM.
   3. Di halaman Program, tekan tombol merah INPUT PROGRAM di kanan bawah:
      pilih customer dari List Customer, lalu pilih programnya
      (INTRODEAL 2+1 / 1+1, BD, atau PROGRAM BARU).

 KALAU BUILD GAGAL DENGAN PESAN "jenisAwal"
 ---------------------------------------
   lib\main.dart:2847:13: Error: No named parameter with the name 'jenisAwal'.

   Artinya lib\main.dart masih versi LAMA (tiga tombol Program), sedangkan
   lib\program.dart sudah versi 18I. Perbaikannya:
      1. Pastikan paket 18I sudah diekstrak (TIMPA semua berkas).
      2. Jalankan LANGKAH1_PASANG_SEMUA.ps1 (menimpa main.dart di akar folder
         DAN lib\main.dart sekaligus).
      3. Jalankan PERIKSA_KODE_APLIKASI.ps1 -> bagian 6f harus [ADA] semua
         dengan putaran 18I.
      4. flutter clean -> flutter pub get -> flutter run
   Sebagai pengaman, lib\program.dart 18I juga menerima permintaan gaya lama,
   jadi build tetap berhasil - tetapi main.dart tetap harus ditimpa supaya
   menu Program benar-benar SATU tombol.

 PEMERIKSAAN SESUDAH PASANG
