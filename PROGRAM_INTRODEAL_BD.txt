 RTS PANEL BY BENE - PANDUAN MENU PRO "PROGRAM"
 VERSI 4 (Putaran 18J, 6 Oktober 2026)
 SATU MENU: LIST CUSTOMER YANG MENGIKUTI PROGRAM + TOMBOL MELAYANG INPUT
==============================================================================

 BACA DULU - APA YANG BERUBAH
 ----------------------------
   Putaran sebelumnya ada beberapa tombol program (Program Introdeal, Program
   BD, Input Program). Sesuai permintaan Bapak, sekarang DIJADIKAN SATU SAJA:

        MENU PRO -> PROGRAM  (List customer & input program)

   Di dalam halaman Program:
        1. LIST CUSTOMER YANG MENGIKUTI PROGRAM (isi utama halaman).
        2. Penyaring SALES DISTRICT (baru pada putaran 18J).
        3. Tombol merah melayang INPUT PROGRAM di kanan bawah.
        4. Ikon PETA di kanan atas (peta & filter program, kunjungan, hari)
           - di dalamnya ada tombol PETA PENUH.
        5. Ikon awan di kanan atas (catatan program yang masih di HP).
        6. Tombol DAFTAR PROGRAM (tambah / ubah / hapus program).

 ARTI PROGRAM
 ------------
   INTRODEAL = Introductory Deal - PROGRAM PAKET.
               Paket bakunya: 2+1 (beli 2 gratis 1) dan 1+1 (beli 1 gratis 1).
               Sales juga dapat membuat PAKET SENDIRI (contoh 3+1).
   BD        = New Brand Distribution - TIDAK memakai paket, karena produknya
               adalah produk baru yang SUDAH ADA di outlet.
   LAIN-LAIN = PROGRAM BUATAN SENDIRI. Bapak dapat membuat program apa saja
               (contoh: PROGRAM GAWIH) dan menentukan apakah memakai paket
               atau tidak.

 ------------------------------------------------------------------------------
 A. MELIHAT LIST CUSTOMER
 ------------------------------------------------------------------------------
   Buka MENU PRO -> PROGRAM. Halaman langsung menampilkan daftar customer:
        - Nama toko dan ID customer.
        - Hari kunjungan dan Sales District toko tersebut.
        - Lencana program yang diikuti (misalnya "INTRODEAL 2+1" atau "BD").
        - Lencana hijau SUDAH DIKUNJUNGI bila toko itu sudah dikunjungi hari
          ini.
        - Jumlah catatan program milik customer itu.

   Catatan 18J: lencana kuning "x BELUM KIRIM" pada tiap baris sudah DIHAPUS
   sesuai permintaan Bapak. Jumlah catatan yang belum dikirim tetap dapat
   dilihat pada ikon awan di kanan atas dan pada menu PRO
   "Backup & Sinkron Data Offline".

   TIGA penyaring di atas daftar:
        1. PROGRAM        : SEMUA PROGRAM / INTRODEAL / BD / program buatan
                            Bapak.
        2. HARI KUNJUNGAN : SEMUA HARI / SENIN ... MINGGU.
        3. KUNJUNGAN      : SEMUA KUNJUNGAN / SUDAH / BELUM (hari ini).
      Contoh: tekan SELASA lalu BELUM -> daftar langsung menampilkan customer
      program yang harus dikunjungi hari Selasa dan belum dikunjungi.
      Teks kecil di bawah penyaring menyebutkan "x dari y customer tampil".

   Melihat riwayat satu customer: KETUK barisnya. Muncul daftar program yang
   pernah dicatat, lengkap dengan:
        - jumlah & satuan, tanggal, dan keterangan sudah/belum dikirim,
        - tombol tempat sampah untuk menghapus satu catatan,
        - tombol TAMBAH PROGRAM untuk menambah catatan program customer itu.

 ------------------------------------------------------------------------------
 B. INPUT PROGRAM (TOMBOL MELAYANG)
 ------------------------------------------------------------------------------
   Tekan tombol merah INPUT PROGRAM di kanan bawah. Muncul halaman berisi:

     1) CUSTOMER
        Tekan PILIH DARI LIST CUSTOMER. Daftar toko dibuka dan sudah DIURUTKAN
        DARI YANG TERDEKAT dengan posisi HP (2 baris teratas = toko terdekat).

     2) PROGRAM
        Pilih INTRODEAL, BD, atau program buatan Bapak.
        Bila programnya memakai paket (contoh INTRODEAL), muncul pilihan:
            2+1   (Beli 2 gratis 1)
            1+1   (Beli 1 gratis 1)
            PAKET SENDIRI (contoh 3+1 - Beli 3 gratis 1)
        Tombol PROGRAM BARU dipakai membuat program baru:
            - Nama program (contoh: PROGRAM GAWIH)
            - Keterangan (boleh kosong)
            - Sakelar "Program memakai PAKET" (nyala = muncul pilihan paket)

     3) PRODUK (dari Menu Barang Bawaan)
        Pilih produk yang ditawarkan. Boleh memilih TANPA PRODUK bila hanya
        ingin mencatat customer yang mengikuti program - isi catatannya.
        Jumlah dan satuan (PACK / BATANG / BALL) diisi bila memakai produk.

     4) PETA LOKASI
        Peta kecil OpenStreetMap berisi titik toko yang dipilih (merah) dan
        titik posisi Bapak (biru).

     5) Tekan SIMPAN DI HP (tombol hijau di kanan bawah).
        Catatan langsung tersimpan DI DALAM HP - TIDAK memerlukan internet.

 ------------------------------------------------------------------------------
 C. MENGELOLA DAFTAR PROGRAM
 ------------------------------------------------------------------------------
   Tombol DAFTAR PROGRAM menampilkan seluruh program:
        - INTRODEAL dan BD adalah program BAWAAN (tidak dapat dihapus).
        - Program buatan Bapak dapat diubah keterangannya atau dihapus.
        - Riwayat input yang sudah dicatat TETAP tersimpan walaupun programnya
          dihapus dari daftar pilihan.

 ------------------------------------------------------------------------------
 D. PETA & FILTER PROGRAM (SEKARANG BISA SATU LAYAR PENUH)
 ------------------------------------------------------------------------------
   Ikon PETA di kanan atas membuka:
        - Peta OpenStreetMap seluruh toko yang ada titiknya.
          Hijau = toko sudah mengikuti program yang dipilih; merah = belum;
          biru = posisi Bapak.
        - Penyaring PROGRAM (SEMUA, INTRODEAL, BD, atau program buatan Bapak).
        - Penyaring KUNJUNGAN (SEMUA / SUDAH / BELUM hari ini).
        - Penyaring HARI (SEMUA, SENIN ... MINGGU).
        - Daftar 30 toko teratas: nama, ID, hari kunjungan, jarak dari posisi
          Bapak, dan lencana SUDAH / BELUM.
        - TOMBOL "PETA PENUH" (baru pada putaran 18J): peta langsung memakai
          SATU LAYAR penuh supaya titik toko terlihat jelas. Penyaring
          PROGRAM / KUNJUNGAN / HARI tetap tersedia di bagian atas peta.
          Tombol silang di kanan atas menutup peta penuh.

 ------------------------------------------------------------------------------
 E. MENGIRIM CATATAN KE SERVER
 ------------------------------------------------------------------------------
   Ikon awan di kanan atas (ada angkanya bila masih ada yang belum dikirim)
   membuka CATATAN PROGRAM DI HP:
        - bisa menghapus satu catatan,
        - tombol KIRIM KE SERVER mengirim seluruh catatan ke server
          (butuh internet) dan menandainya sudah dikirim.
   Rincian data di HP juga dapat dilihat pada menu PRO
   "Backup & Sinkron Data Offline".

 ------------------------------------------------------------------------------
 F. SINKRONISASI DATA (SUDAH DIPUSATKAN)
 ------------------------------------------------------------------------------
   Sesuai permintaan Bapak, tombol SINKRON di dalam menu sudah DIHAPUS
   (SINKRON PRODUK di Barang Bawaan, SEGARKAN di Peta Customer & Rute Plan,
   dan SINKRON ONLINE di Program). Sinkronisasi sekarang lewat MENU UTAMA ->
   SINKRONISASI -> tombol SINKRONKAN SEKARANG, yang sekaligus menarik:
        status AKUN (PRO/GRATIS), PRODUK (SKU & harga), dan DAFTAR TOKO.

 ------------------------------------------------------------------------------
 G. DATA CUSTOMER PER SALES DISTRICT (BARU PUTARAN 18J)
 ------------------------------------------------------------------------------
   Supaya aplikasi tidak berat (dulu 3170 toko sekaligus membuat peta
   tersendat), setiap halaman menu PRO memuat BARIS PENYARING SALES DISTRICT:
        - RTS dan TF : TERKUNCI pada Sales District akunnya.
        - WSS, SMST, ADMIN, dan ASS : dapat memilih SEMUA DISTRICT atau satu
          district saja. Tombol district dapat digeser ke samping dan memuat
          jumlah toko tiap district.
   Pilihan disimpan di HP, sehingga seluruh menu PRO (Peta Customer, Radar
   Customer, Rute Plan, Pilih Toko Kasir, dan Program) memakai pilihan yang
   sama. Bila Bapak memilih SEMUA DISTRICT, peta berhenti menggambar sesudah
   1200 titik dan menampilkan pesan kuning yang meminta memilih district.
