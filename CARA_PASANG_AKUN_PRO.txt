 YANG DIPERBAIKI PADA VERSI 2
===============================================================================
 Versi 1 gagal pada phpMyAdmin dengan pesan:

    #1044 - Access denied for user 'cpses_begpopoyvq'@'localhost'
            to database 'information_schema'

 Sebabnya: berkas SQL versi 1 memakai tabel information_schema untuk memeriksa
 kolom. Akun database cPanel tidak diberi izin membaca tabel itu, sehingga
 phpMyAdmin BERHENTI pada baris pertama dan perintah ALTER TABLE (yang
 sebenarnya menambah kolom) tidak pernah dijalankan.

 Yang diperbaiki pada versi 2:
   1. Berkas SQL tidak lagi memakai information_schema - diganti SHOW COLUMNS
   2. akun_pro.php juga tidak lagi memakai information_schema
   3. api/kolom.php dan api/login.php ikut diperbaiki dengan cara yang sama

===============================================================================
 CARA TERCEPAT (SATU BARIS DI phpMyAdmin)
===============================================================================
 1. Buka cPanel - phpMyAdmin
 2. Klik database benedics_bene_sales pada panel kiri
 3. Klik tab SQL
 4. Tempel SATU baris berikut:

      ALTER TABLE sales_users ADD COLUMN akun_pro TINYINT(1) NOT NULL DEFAULT 0;

 5. Klik Kirim
 6. Bila muncul "#1060 - Duplicate column name 'akun_pro'", artinya kolomnya
    SUDAH ADA - tidak ada yang rusak, lanjutkan ke langkah berikutnya

 Hanya perintah itu yang benar-benar diperlukan. Perintah lainnya (pemeriksaan
 dan ringkasan) sudah disertakan di dalam berkas RTS_PANEL_AKUN_PRO.sql dan
 bersifat pilihan.

===============================================================================
 BILA ADA MASALAH
===============================================================================
 Muncul "#1044 Access denied ... to database 'information_schema'"
    Berarti berkas SQL versi LAMA yang dipakai. Pakai RTS_PANEL_AKUN_PRO.sql
    dari paket VERSI 2 ini (tidak memakai information_schema), atau cukup
    jalankan satu baris ALTER TABLE pada bagian "CARA TERCEPAT".

 Muncul "#1060 Duplicate column name 'akun_pro'"
    Kolomnya sudah ada. Tidak ada yang rusak. Lanjutkan ke langkah website.

 Muncul "#1144 Access denied" pada ALTER TABLE
    Akun database yang dipakai phpMyAdmin tidak berhak mengubah tabel. Buat
    pengguna database lewat cPanel - MySQL Databases, beri ALL PRIVILEGES
    untuk database tersebut, lalu ulangi.

 Halaman akun_pro.php masih menampilkan peringatan kolom
    Muat ulang halaman (Ctrl+F5). Bila tetap, pastikan berkas akun_pro.php
    yang diunggah adalah dari paket VERSI 2 ini.

 Status PRO diubah tetapi iklan masih tampil
    Pengguna perlu LOGIN KEMBALI - status dibaca saat login.
