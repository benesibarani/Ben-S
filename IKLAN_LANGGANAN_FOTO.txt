 BAGIAN 2 - LANGGANAN PRO: QRIS, 30 HARI, UJI COBA 7 HARI
==============================================================================

  A. ATURAN YANG DIPAKAI
     Uji coba (TRIAL) : 7 hari, SEKALI saja untuk setiap akun, diberikan
                        OTOMATIS saat petugas masuk (login) pertama kali
                        setelah pembaruan ini dipasang. Selama uji coba,
                        seluruh iklan dimatikan.
     Langganan (PRO)  : 30 hari setiap kali pembayaran diterima Admin.
                        Harga  : Rp5.000 (dapat diubah, lihat bagian D)
                        Nominal pada gambar QRIS Bapak memang Rp5.000.
     Perpanjangan     : bila masa PRO masih berjalan dan membayar lagi, masa
                        barunya DITAMBAHKAN dari tanggal berakhir yang lama
                        (tidak hangus).
     Setelah masa habis, akun otomatis kembali GRATIS dan iklan muncul lagi.

  B. HALAMAN BARU DI DALAM APLIKASI
     Letak  : Profil - Rencana Akun - tombol "LANGGANAN PRO"
              (tombol berubah menjadi "KELOLA LANGGANAN" bila sudah PRO)
     Isinya : - keadaan langganan + sisa hari
              - gambar QRIS + nominal + NMID
              - 5 langkah cara berlangganan
              - tombol "SAYA SUDAH BAYAR"
              - kartu uji coba gratis 7 hari
              - keterangan lengkap

     Alur pembayaran:
       1. Petugas memindai QRIS dengan aplikasi bank / dompet digital
       2. Petugas membayar Rp5.000
       3. Petugas menekan "SAYA SUDAH BAYAR" pada aplikasi
       4. Pernyataan itu tercatat di database dan mengirim pemberitahuan ke
          Admin (aplikasi + layar HP)
       5. Admin membuka halaman langganan_admin.php di website lalu menekan
          tombol "SETUJUI + 30 HARI"
       6. Akun PRO petugas langsung aktif 30 hari - iklan hilang tanpa perlu
          memasang ulang aplikasi

  C. GAMBAR QRIS BAPAK
     Gambar QRIS TIDAK ikut di dalam paket ini (gambar dikirim lewat WhatsApp,
     bukan sebagai berkas proyek). Bapak cukup memasangnya sendiri - ada dua
     cara, pilih salah satu:

     CARA 1 (paling mudah - memakai skrip yang saya sediakan)
        [ ] 1. Simpan gambar QRIS dari WhatsApp ke HP/komputer (Unduhan)
        [ ] 2. Buka PowerShell, masuk ke folder proyek:
                  cd D:\Project\rts_panel_app
        [ ] 3. Jalankan:
                  .\PASANG_GAMBAR_QRIS.ps1
               Skrip mencari gambar QRIS terbaru di folder Unduhan/Desktop,
               menampilkan pilihannya, lalu menyalinnya dengan nama yang benar
        [ ] 4. flutter clean
        [ ] 5. flutter run -d CPH1937

     CARA 2 (manual, sama hasilnya)
        [ ] 1. Buka folder D:\Project\rts_panel_app\assets\images
        [ ] 2. Salin gambar QRIS ke folder itu
        [ ] 3. Ubah namanya menjadi persis:  qris_bene_s.jpg
        [ ] 4. flutter clean  lalu  flutter run -d CPH1937

     Nama berkas HARUS persis "qris_bene_s.jpg" (huruf kecil, berakhiran .jpg).
     Selama gambar belum ada, halaman Langganan PRO tetap terbuka dan
     menampilkan keterangan NMID + nominal, dengan pesan pengingat.

  D. MENGUBAH HARGA / LAMA LANGGANAN (bila perlu nanti)
     Buka berkas api/langganan_inti.php pada hosting, ubah angka pada:
        function rts_lg_harga()   -> 5000    (harga rupiah)
        function rts_lg_durasi()  -> 30      (lama PRO, hari)
        function rts_lg_trial()   -> 7       (lama uji coba, hari)
     Satu perubahan itu langsung berlaku pada aplikasi dan website.

  E. HALAMAN PENGELOLAAN UNTUK ADMIN (website)
     Alamat : https://rts.benedic-s.com/langganan_admin.php
              (hanya dapat dibuka akun role ADMIN)
     Isinya : - daftar seluruh akun + keadaan PRO/TRIAL/GRATIS + sisa hari
              - tombol "+30 HARI", "+90 HARI", "TRIAL 7 HARI", "HENTIKAN"
              - daftar pernyataan pembayaran QRIS + tombol SETUJUI / TOLAK
              - tombol "PERBARUI DATABASE" (membuat kolom baru, aman)
              - tempat menyimpan gambar QRIS untuk website
              - tautan ?diagnosa=1 untuk memeriksa keadaan halaman

     Halaman akun_pro.php yang lama TETAP dapat dipakai seperti biasa.

 BAGIAN 3 - FOTO PRIBADI SETIAP PENGGUNA
==============================================================================

  A. CARA PAKAI DI APLIKASI
     Profil - foto pada kartu merah (ada tanda kamera kecil) - ketuk
        -> Ambil dari Kamera
        -> Pilih dari Galeri
        -> Hapus Foto

     Foto dipotong dan diperkecil otomatis (maksimal 900 x 900 titik), lalu
     disimpan ke server pada folder uploads/foto_profil/. Ukuran paling besar
     2 MB. Foto tampil pada kartu akun di halaman Profil dan Beranda.

  B. YANG PERLU DITAMBAHKAN DI ANDROIDMANIFEST
     Izin kamera (hanya untuk mengambil foto langsung dari kamera):
        <uses-permission android:name="android.permission.CAMERA" />
     Sudah ada pada berkas android_manifest_tambahan.xml paket ini. Memilih
     foto dari galeri TIDAK memerlukan izin tambahan.

  C. PENGGUNAAN DI WEBSITE
     Halaman langganan_admin.php menampilkan foto (bulat kecil) di samping
     nama petugas, sehingga Admin mudah mengenali akun.

 BAGIAN 6 - MENYETUJUI PEMBAYARAN LANGSUNG DARI HP (KHUSUS ADMIN)
==============================================================================

 Permintaan Bapak (sebelum rilis):
   "Role Admin tidak ada mengubah status PRO atau GRATIS dari member.
    Padahal member sudah bayar dan notifikasinya sudah masuk."

 SEKARANG SUDAH ADA. Halaman baru di dalam aplikasi: KELOLA AKUN PRO.

  A. CARA MEMBUKANYA
     Profil - Rencana Akun - tombol "KELOLA AKUN PRO (ADMIN)"
     (tombol itu hanya tampil bila akun yang masuk berperan ADMIN)

     Cara kedua: ketuk pemberitahuan "Pembayaran Akun PRO" yang masuk ke HP
     Admin - aplikasi langsung membuka halaman ini.

  B. ISI HALAMANNYA
     Bagian atas - PEMBAYARAN MENUNGGU
        Setiap pernyataan pembayaran dari petugas berupa satu kartu:
           nama petugas, username, role, nominal, lama hari, waktu dinyatakan
           tombol  [SETUJUI + 30 HARI]   [TOLAK]
        Menekan SETUJUI:
           - masa PRO 30 hari langsung diberikan kepada petugas itu
           - pernyataan pembayarannya ditandai DIBAYAR
           - petugas menerima pemberitahuan "Pembayaran Diterima - Akun PRO
             Aktif" di layar HP-nya

     Bagian bawah - DAFTAR AKUN
        Seluruh akun beserta foto, role, dan keadaan langganannya:
           PRO            : hijau
           UJI COBA       : kuning
           GRATIS         : merah
        Tombol pada setiap akun:
           [+30 HARI]   menambah 30 hari (masa lama DITAMBAHKAN, tidak hangus)
           [+90 HARI]   menambah 90 hari
           [TRIAL 7 HARI] hanya tampil bila akun itu belum pernah uji coba
           [HENTIKAN]   akun kembali GRATIS, iklan tampil kembali
        Ada juga kolom pencarian nama / username / role.

     Bila kolom database belum lengkap, di bagian atas muncul kartu dengan
     tombol "PERBARUI DATABASE" - tekan sekali saja, sama seperti pada website.

  C. SETELAH ADMIN MENYETUJUI
     Petugas tidak perlu memasang ulang aplikasi dan tidak perlu keluar-masuk
     berkali-kali. Keadaan PRO dibaca setiap aplikasi dibuka, jadi begitu
     aplikasi dibuka (atau sesi diperbarui), iklan langsung hilang.

  D. HUBUNGAN DENGAN HALAMAN WEBSITE
     Halaman website langganan_admin.php TETAP ADA dan tetap dapat dipakai
     bila Bapak sedang memakai komputer. Keduanya memakai aturan yang sama
     (api/langganan_inti.php), sehingga hasilnya selalu seragam.

 BAGIAN 7 - NAMA APLIKASI PADA LAYAR HP
==============================================================================

 Permintaan Bapak: nama aplikasi di HP sebelumnya "rts_panel_app" - kurang
 enak dilihat. Sekarang menjadi:   RTS Panel

 Cara mengubahnya TIDAK perlu manual: skrip LANGKAH1_PASANG_SEMUA.ps1
 mengerjakannya otomatis (langkah 5 dari 8). Skrip itu:
   1. membaca AndroidManifest.xml
   2. membuat cadangan berkasnya
   3. mengganti tulisan android:label="rts_panel_app"  menjadi
      android:label="RTS Panel"
   4. memastikan hasilnya

 Yang TIDAK berubah: nama paket aplikasi (com.example.rts_panel_app) dan
 applicationId-nya. Ini DISENGAJA, supaya aplikasi baru dapat menimpa
 aplikasi lama tanpa menghapus - setelan, sesi login, dan data di HP tetap
 aman. Bila nama paket diubah, seluruh HP harus menghapus aplikasi lama
 terlebih dahulu (dan itu merepotkan banyak orang).

 Nama baru terlihat di:
   - daftar aplikasi pada layar HP
   - judul pada daftar aplikasi terbaru (recent apps)
   - halaman Pengaturan - Aplikasi - RTS Panel
