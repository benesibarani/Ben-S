==============================================================================
 4. LANGKAH PEMASANGAN (URUT, JANGAN DIBOLAK-BALIK)
==============================================================================

 A. DI HOSTING (cPanel)
    1. Buka File Manager -> public_html -> folder api
    2. Unggah api/cctv.php  (pilih TIMPA bila diminta)
    3. Pastikan periksa_cctv.php ada di public_html dan data/cctv_medan.json
       ada di public_html/data/
    4. Bila pernah menjalankan migrasi database, cukup lewati; tahap 2 TIDAK
       memerlukan perubahan database.
    5. Uji di peramban:  https://<alamat-situs>/periksa_cctv.php
       Harus terbaca "111 kamera" dan tautan contoh hidup.

 B. DI KOMPUTER (proyek Flutter  D:\Project\rts_panel_app)
    1. Ekstrak paket RTS_PANEL_PUTARAN_18E.zip (pilih TIMPA / Replace semua).
    2. Klik kanan LANGKAH1_PASANG_SEMUA.ps1 -> Run with PowerShell.
       Skrip itu menyalin main.dart, cctv.dart, pubspec.yaml, dan berkas
       pendukung lain ke proyek Bapak (berkas lama dicadangkan otomatis).
    3. Buka terminal di folder proyek, jalankan berurutan:
           flutter clean
           flutter pub get
           flutter analyze        (memeriksa kode - sebaiknya 0 galat)
           flutter build apk --release
    4. Bila `flutter pub get` menuliskan pesan bahwa paket video_player
       memerlukan versi Flutter yang lebih baru, jalankan `flutter upgrade`
       lalu `flutter pub get` kembali. (Nomor versi sengaja ditulis mulai
       dari angka rendah supaya dipilihkan versi yang cocok.)
    5. Pasang APK ke HP. JANGAN menghapus aplikasi lama di HP - cukup
       timpa (data kasir/POM di HP tetap aman).

 C. DI HP
    1. Buka aplikasi -> beranda -> MENU PRO -> CCTV Online.
    2. Bila muncul "Daftar kamera tidak dapat diambil", tekan tombol
       SEGARKAN (ikon awan di kanan atas).

 5. CARA MEMAKAI MENU CCTV ONLINE
==============================================================================

   1. Ketik nama jalan pada kotak pencarian (contoh: kesawan, jamin, ahmad).
   2. Atau tekan tombol "Pakai lokasi" supaya kamera TERDEKAT muncul di
      atas (aplikasi meminta izin lokasi sekali saja).
   3. Tekan tombol PUTAR pada kamera yang dipilih.
   4. Di dalam pemutar:
        - tombol play/pause, bisukan, dan muat ulang ada di bawah gambar;
        - tombol PETA menampilkan lokasi kamera (OpenStreetMap) lengkap
          dengan tombol BUKA DI GOOGLE MAPS;
        - tombol SALIN menyalin tautan .m3u8 (bisa dikirim ke rekan kerja);
        - tombol LAYAR PENUH memutar video satu layar penuh (miring);
        - tombol VLC membuka siaran di aplikasi lain.
   5. Tekan tombol SEGARKAN (ikon awan) pada halaman daftar untuk mengambil
      daftar terbaru dari server. Bila Dishub menambah kamera baru, kamera
      itu langsung ikut muncul - tanpa membangun ulang aplikasi.


==============================================================================
 6. BILA ADA MASALAH
==============================================================================

 "Daftar kamera belum tersedia..."
     Server belum punya data/cctv_medan.json. Buka di peramban:
         https://<alamat-situs>/periksa_cctv.php?ambil=1
     lalu tekan SEGARKAN di aplikasi.

 "Server belum memuat daftar kamera..."
     Sama seperti di atas - data belum diambil. Jalankan periksa_cctv.php?ambil=1.

 "Kamera sedang tidak tersedia."
     Kamera itu sedang dimatikan / diperbaiki Dishub, atau jaringan lambat.
     Coba kamera lain, atau coba lagi beberapa saat kemudian. Bila SEMUA
     kamera begitu, periksa koneksi internet HP (coba buka YouTube).

 Video jalan tetapi tersendat
     Turunkan kualitas jaringan (siaran ini dari server Dishub, bukan dari
     server RTS Panel - kecepatannya berbeda-beda).

 "Menu ini khusus AKUN PRO."
     Akun Bapak masih GRATIS. Buka menu Langganan PRO, lalu SINKRON AKUN.
     Bila sudah PRO tetapi masih tertolak, tekan SINKRON AKUN pada menu
     Sinkronisasi (status PRO diperbarui dari server).

 Video tidak mau jalan padahal kamera hidup
     Tekan tombol VLC pada pemutar - bila di VLC jalan berarti HP hanya
     kurang cocok memutar HLS; laporkan ke saya supaya saya tambahkan
     pilihan pemutar lain.

   - Siaran CCTV milik DINAS PERHUBUNGAN KOTA MEDAN (ATCS / ITS Kota Medan)

 8. HASIL PENGUJIAN YANG SUDAH SAYA LAKUKAN
==============================================================================

   Pengujian otomatis api/cctv.php (PHP 8.2 asli) - 47 pemeriksaan LULUS:
     - tanpa token -> 401;  akun GRATIS -> 403 + perlu_pro = true
       (dan tidak ada satu pun tautan kamera yang terbocor pada balasan itu);
     - akun PRO -> 111 kamera, kode tidak kembar, tautan berpola benar,
       daftar terurut menurut nomor kamera, koordinat masuk akal;
     - ADMIN dan ASS tetap boleh membuka walau tanpa langganan;
     - aksi=uji&jumlah=5 memeriksa 5 kamera; aksi=uji&kode=... hanya kamera
       yang diminta; kode yang tidak dikenal -> 200 dengan 0 kamera;
     - aksi=segarkan saat internet ke situs Dishub terputus -> tetap 200 dan
       daftar lama dipakai (aplikasi tidak eror);
     - berkas data tidak berubah saat aplikasi hanya membaca daftar.
   Pemeriksaan kode aplikasi: kurung lib\cctv.dart & main.dart berimbang,
   dan 29 nama fungsi peta/warna yang dipakai cctv.dart benar-benar ada.
   Catatan jujur: pengujian di dalam HP (memutar video) harus Bapak lakukan
   sendiri, karena saya tidak dapat memasang aplikasi di HP Bapak. Bila ada
   yang tidak berjalan, kirim tangkapan layarnya - saya perbaiki.

==============================================================================
 2. MENGAMBIL DAFTAR SELURUH KAMERA (111 KAMERA)
==============================================================================

 Situs ATCS memakai API resmi berisi daftar seluruh kamera (nama, koordinat,
 gambar) untuk menampilkan halaman streaming mereka. Alat periksa_cctv.php
 mengambil daftar itu, lalu menyimpannya untuk dipakai aplikasi.

 CARA PAKAI (setelah periksa_cctv.php diunggah ke public_html):

    periksa_cctv.php                  keadaan hosting & petunjuk
    periksa_cctv.php?ambil=1          ambil daftar kamera dari API ATCS
    periksa_cctv.php?paksa=1&ambil=1  ambil ulang (memaksa, walau masih baru)
    periksa_cctv.php?uji=10           uji 10 tautan pertama (HIDUP / MATI)
    periksa_cctv.php?uji=semua        uji SELURUH tautan
    periksa_cctv.php?unduh=1          unduh data/cctv_medan.json

 HASIL
    data/cctv_medan.json  -> daftar kamera (kode, nomor, nama, alias, tautan,
                             koordinat). BERKAS INILAH yang nanti dibaca
                             aplikasi pada menu CCTV Online.

 KEUNTUNGAN CARA INI
    - Bapak tidak perlu menyusun daftar kamera satu per satu.
    - Bila Dishub menambah atau mengganti kamera, cukup buka
      periksa_cctv.php?paksa=1&ambil=1 -> daftar diperbarui, dan
      APLIKASI TIDAK PERLU DIBANGUN ULANG.
    - Alat ini juga menampilkan CONTOH DATA MENTAH dari API, supaya nama
      kolom (field) yang tersedia jelas terbaca bila suatu saat berubah.

 SUDAH DISIAPKAN JUGA (tidak wajib, hanya agar cepat)
    cctv_medan.json  -> daftar 111 kamera yang saya ambil dari sini.
      Bila ingin langsung memakainya tanpa menunggu hosting menyambung ke
      ATCS, buat folder "data" di dalam public_html lalu letakkan berkas ini
      di dalamnya dengan nama:  data/cctv_medan.json
    cctv_medan.m3u   -> daftar putar untuk mencoba semua kamera TANPA aplikasi:
      buka VLC -> Media -> Open Network Stream (Ctrl+N) -> pilih berkas ini.

==============================================================================
 5. CATATAN PENTING
==============================================================================

   - periksa_cctv.php HANYA MEMBACA. Tidak ada data Bapak yang diubah atau
     dihapus.
   - Kunci API yang dipakai adalah kunci PUBLIK milik situs ATCS: nilainya
     dapat dibaca siapa saja pada berkas JavaScript halaman mereka. Itu BUKAN
     kunci RTS Panel dan tidak memuat data Bapak. Bila Dishub menggantinya,
     cukup ubah dua baris pada periksa_cctv.php atau buat berkas
     cctv_kunci.php berisi kunci yang baru.
   - Hasil pengambilan DISIMPAN 12 jam supaya server Dishub tidak dibebani.
     Pakai ?paksa=1 bila ingin mengambil ulang lebih cepat.
   - Kamera yang tampak MATI pada ?uji=semua biasanya sedang dimatikan atau
     dalam perbaikan oleh Dishub - bukan kesalahan aplikasi.
   - Siaran ini milik Dinas Perhubungan Kota Medan dan terbuka untuk umum.
     Aplikasi hanya memakai tautan yang sama seperti yang dibuka di browser,
     jadi tidak ada kata sandi atau data rahasia yang perlu dimasukkan.
   - Tautan dapat berubah bila Dishub mengganti nama/nomor kamera. Karena itu
     daftar sebaiknya diambil ulang (periksa_cctv.php?paksa=1&ambil=1) bila
     ada kamera yang tidak lagi dapat diputar.
