 BACA DULU - ARTI DUA PROGRAM (sesuai penjelasan Bapak)
 ------------------------------------------------------
   INTRODEAL = Introductory Deal.
               Ini PROGRAM PAKET. Paket bakunya:
                 - 2+1  artinya beli 2 gratis 1
                 - 1+1  artinya beli 1 gratis 1
               Sales juga boleh membuat PAKET SENDIRI, contoh 3+1.
               Produknya diambil dari MENU BARANG BAWAAN.

   BD        = New Brand Distribution.
               TIDAK ADA program / paket. Hanya PRODUK, karena produknya
               adalah produk baru yang SUDAH ADA di outlet.

 CARA MEMBUKA
 ------------
   Beranda -> MENU PRO (boleh diminimize) -> pilih salah satu:
     Program Introdeal        : paket 2+1 / 1+1 / PAKET SENDIRI
     Program BD               : produk BD saja
     Input Program            : langsung ke form CATAT PROGRAM
     Peta & Filter Program    : langsung ke peta + penyaring
     Backup & Sinkron Data Offline : data yang tersimpan di HP

 ------------------------------------------------------------------------------
 A. PROGRAM INTRODEAL (PROGRAM PAKET)
 ------------------------------------------------------------------------------
  1. Di bawah tombol-tombol ada tulisan "PAKET INTRODEAL (pilih satu)".
     Ketuk salah satu paket:
        2+1  (Beli 2 gratis 1)   - paket bawaan, tidak bisa dihapus
        1+1  (Beli 1 gratis 1)   - paket bawaan, tidak bisa dihapus
        3+1, 4+2, dst            - PAKET SENDIRI buatan Sales
  2. Tekan  PAKET SENDIRI  untuk membuat paket baru:
        - Nama paket : contoh 3+1
        - Keterangan : contoh Beli 3 gratis 1
        - Tekan SIMPAN. Paket langsung muncul dan bisa dipilih.
  3. Menghapus paket: ketuk tanda silang kecil di paket buatan Sales.
     Paket bawaan 2+1 dan 1+1 TIDAK dapat dihapus (aman).
  4. Produk:
        DARI BARANG BAWAAN : mengambil satu produk dari daftar bawaan
        SINKRON ONLINE     : mengambil daftar dari server (api/program.php)
        TAMBAH PRODUK      : mengetik produk sendiri
  5. ADMIN / ASS dapat menekan KIRIM KE SERVER pada tiap produk supaya
     dipakai HP Sales lain.

 ------------------------------------------------------------------------------
 B. PROGRAM BD (NEW BRAND DISTRIBUTION)
 ------------------------------------------------------------------------------
  - Tidak ada paket. Muncul keterangan "Sub-menu BD (New Brand
    Distribution): TIDAK memakai paket - produknya sudah ada di outlet."
  - Isinya hanya daftar PRODUK BD. Cara mengisi produk sama seperti
    Introdeal: DARI BARANG BAWAAN / SINKRON ONLINE / TAMBAH PRODUK.

 ------------------------------------------------------------------------------
 C. INPUT PROGRAM TANPA INTERNET (INPUT OFFLINE)
 ------------------------------------------------------------------------------
  1. Pilih toko dulu: tombol  PILIH TOKO TERDEKAT  (memakai posisi GPS HP).
  2. Tekan  CATAT PROGRAM  (tombol hijau).
  3. Form berisi:
        - PETA KECIL OpenStreetMap: titik toko terpilih + titik posisi Bapak.
        - Produk program (pilihan dari daftar produk di HP).
        - Jumlah, Satuan (PACK / BATANG / BALL), dan Catatan.
  4. Tekan SIMPAN DI HP. Catatan TIDAK memerlukan internet.
  5. Melihat catatan: tombol  CATATAN TERSIMPAN  atau ikon awan di kanan
     atas (ada angkanya bila masih ada yang belum dikirim).
  6. Bila sudah ada internet: buka CATATAN TERSIMPAN -> KIRIM KE SERVER.
     Catatan yang berhasil dikirim otomatis ditandai sudah dikirim.
     (Server menyimpan di tabel rts_program_input; catatan yang sama tidak
      masuk dua kali.)

 ------------------------------------------------------------------------------
 D. PETA & FILTER (INTRODEAL / BD, KUNJUNGAN, HARI)
 ------------------------------------------------------------------------------
  Tekan  PETA & FILTER (PROGRAM, KUNJUNGAN, HARI). Isinya:
     - Peta OpenStreetMap seluruh toko yang ada titiknya.
       Titik hijau = toko sudah ada catatan/dibeli untuk program terpilih;
       titik abu-abu = belum; titik biru = posisi Bapak.
     - Penyaring PROGRAM   : INTRODEAL atau BD.
     - Penyaring KUNJUNGAN : SEMUA / SUDAH / BELUM (kunjungan hari ini).
     - Penyaring HARI      : SEMUA, SENIN ... MINGGU (hari kunjungan toko).
     - Daftar 30 toko teratas: Nama, ID, hari, jarak dari posisi Bapak,
       dan lencana SUDAH / BELUM.

 ------------------------------------------------------------------------------
 E. BACKUP & SINKRON DATA OFFLINE (MENU PRO BARU)
 ------------------------------------------------------------------------------
  Membuka menu ini menampilkan DATA DI DALAM HP:
     Kunjungan, Nota kasir, Input program, Piutang, Program produk,
     Paket Introdeal, Toko tersimpan, Produk tersimpan, Goresan peta,
     Titik kantor.
  Tiap baris menunjukkan berapa yang BELUM DIKIRIM.
  Tombol:
     LIHAT DATA SIAP KIRIM : melihat & menyalin isi data belum kirim
                             (untuk dilaporkan ke ASS / Admin).
     SALIN RINGKASAN       : menyalin ringkasan angka (tempel ke WhatsApp).
     TANDAI SUDAH DIKIRIM  : menandai data sudah masuk ke pusat.
     BUAT CADANGAN DI HP   : membuat berkas cadangan .db di dalam HP.
