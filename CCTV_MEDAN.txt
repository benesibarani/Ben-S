 Menu baru pada MENU PRO di Beranda:  CCTV Online

   Menu ini dibuat MENIRU halaman resmi ATCS Dishub
   (https://atcsdishub.medan.go.id/streaming) supaya terasa tidak asing:

   A. TIGA TAMPILAN - sama seperti tab "Peta" dan "Grid Kamera" di situs itu,
      ditambah satu:
        DAFTAR       - daftar memanjang, satu kamera satu baris (paling ringan).
        GRID KAMERA  - kotak-kotak berisi GAMBAR kamera + tombol Play
                       (seperti "Grid Kamera" pada situs Dishub).
        PETA         - SELURUH kamera sebagai titik pada satu peta
                       (seperti tab "Peta" pada situs Dishub); ketuk titik
                       kamera untuk langsung memutar.

   B. LENCANA SIAP / TIDAK TERSEDIA - seperti lencana READY / MAINTENANCE pada
      situs Dishub. Tekan tombol PERIKSA: server memeriksa seluruh kamera
      sekaligus (serentak, dibatasi 20 detik) lalu hasilnya disimpan 10 menit,
      jadi daftar berikutnya sudah membawa status itu tanpa memanggil ulang.
      Kamera yang mati ditandai TIDAK TERSEDIA dan tombol PERIKSA pada kartu
      otomatis tidak ditawarkan.

   C. DAFTAR KAMERA DIBACA DARI SERVER (api/cctv.php), bukan ditanam di dalam
      aplikasi. Bila Dishub menambah/mengganti kamera, cukup tekan ikon awan
      (SEGARKAN) - aplikasi TIDAK perlu dibangun ulang. Gambar kamera pun
      dilengkapi sendiri oleh server dari situs Dishub (paling banyak sekali
      setiap 6 jam, supaya hosting tidak dibebani).

   D. PENCARIAN - ketik "kesawan", "jamin", atau nomor kamera.
   E. URUTAN - Nama / Nomor / TERDEKAT (menurut jarak dari posisi HP).
   F. PEMUTAR LANGSUNG DI DALAM APLIKASI (siaran HLS). Di dalam pemutar ada:
      play/pause, bisukan, muat ulang, PETA lokasi kamera, SALIN TAUTAN,
      dan LAYAR PENUH. Ada juga tombol VLC/peramban bila HP kesulitan.
   G. HEMAT KUOTA - pada tampilan Grid ada tombol "Gambar: TAMPIL / HEMAT
      KUOTA". Bila gambar dimatikan, kartu memakai gambar pengganti sehingga
      kuota data jauh lebih hemat (lencana dan tombol Play tetap bekerja).
   H. KHUSUS AKUN PRO - dikunci di aplikasi DAN diperiksa ulang di server
      (akun GRATIS ditolak dengan kode 403 + perlu_pro). ADMIN dan ASS tetap
      boleh membuka (pengelola).
   I. DAFTAR & STATUS DISIMPAN DI DALAM HP, sehingga nama kamera dan lencana
      terakhir tetap terbaca walau HP sedang tanpa internet (videonya tentu
      tetap perlu internet).

    2. Unggah api/cctv.php  (pilih TIMPA bila diminta)

       `flutter upgrade` lalu `flutter pub get` kembali.
    5. Pasang APK ke HP dengan cara MENIMPA. JANGAN menghapus aplikasi lama
       di HP - data Kasir & STRUK POM tetap aman.

 C. DI HP

    2. Bila muncul "Daftar kamera tidak dapat diambil", tekan ikon awan

 5. CARA MEMAKAI MENU CCTV ONLINE
==============================================================================

   A. PILIH TAMPILAN (tiga tombol di atas):
        DAFTAR | GRID KAMERA | PETA
        Tampilan terakhir tidak perlu dipilih ulang setiap membuka menu -
        cukup tekan tombolnya sekali.

   B. CARI & URUTKAN (tampilan Daftar dan Grid):
        - kotak pencarian: ketik nama jalan, nama simpang, atau nomor kamera;
        - tombol Nama / Nomor / TERDEKAT. Tombol "Pakai lokasi" meminta izin
          lokasi sekali, lalu kamera terdekat muncul di atas.

   C. MEMUTAR VIDEO:
        - tampilan Daftar: tekan PUTAR;
        - tampilan Grid : tekan tombol Play pada gambar kamera;
        - tampilan Peta : ketuk titik kamera (atau tombol TERDEKAT).
        Di dalam pemutar: play/pause, bisukan, muat ulang, PETA, SALIN, LAYAR
        PENUH, dan VLC.

   D. MEMERIKSA KAMERA (SIAP / TIDAK TERSEDIA):
        - tekan PERIKSA (tulisan kecil di baris keterangan) atau ikon
          gelombang pada judul halaman;
        - tunggu beberapa detik (server memeriksa seluruh kamera sekaligus);
        - kamera yang siap diputar diberi lencana hijau SIAP, yang mati
          diberi lencana merah TIDAK TERSEDIA. Hasilnya berlaku 10 menit.

   E. MENGHEMAT KUOTA:
        - pada tampilan Grid, tekan tombol "Gambar: TAMPIL" menjadi
          "HEMAT KUOTA" bila ingin mematikan gambar kamera;
        - video siaran tetap memakai kuota selama diputar.


==============================================================================
 6. BILA ADA MASALAH
==============================================================================

 "Daftar kamera belum tersedia..."
     Server belum punya data/cctv_medan.json. Buka di peramban:
         https://<alamat-situs>/periksa_cctv.php?ambil=1
     lalu tekan SEGARKAN di aplikasi.

 "Server belum memuat daftar kamera..."
     Sama seperti di atas - data belum diambil. Jalankan periksa_cctv.php?ambil=1.

 "Kamera sedang tidak tersedia."
     Kamera itu sedang dimatikan / diperbaiki Dishub, atau jaringan lambat.
     Lihat lencana pada tampilan Grid/Peta: yang bertanda TIDAK TERSEDIA
     memang sedang mati. Coba kamera lain, atau coba lagi nanti.

 Gambar kamera tidak muncul (tampilan Grid)
     1. Pastikan tombol "Gambar: TAMPIL" sedang aktif (bukan HEMAT KUOTA).
     2. Server menyimpan daftar lama yang belum memuat gambar. Tekan ikon awan
        (SEGARKAN). Server akan melengkapi gambar dari situs Dishub (paling
        banyak sekali setiap 6 jam). Bila situs Dishub tidak dapat dihubungi,
        kartu memakai gambar pengganti - aplikasi tetap berjalan normal.

 Tombol PERIKSA tidak ada / tidak muncul
     Berarti server masih memakai api/cctv.php versi lama. Unggah api/cctv.php
     dari paket ini ke public_html/api/ (TIMPA), lalu tekan SEGARKAN.

 "Menu ini khusus AKUN PRO."
     Akun Bapak masih GRATIS. Buka menu Langganan PRO, lalu SINKRON AKUN.

 Video jalan tetapi tersendat
     Siaran ini dari server Dishub, bukan dari server RTS Panel - kecepatannya
     berbeda-beda. Coba kamera lain atau tunggu beberapa saat.

 Video tidak mau jalan padahal lencana SIAP
     Tekan tombol VLC pada pemutar. Bila di VLC jalan berarti HP hanya kurang
     cocok memutar HLS - laporkan ke saya supaya saya tambahkan pilihan lain.

 8. HASIL PENGUJIAN YANG SUDAH SAYA LAKUKAN
==============================================================================

   Pengujian otomatis api/cctv.php (PHP 8.2 asli) - 76 pemeriksaan LULUS:
     - tanpa token -> 401;  akun GRATIS -> 403 + perlu_pro = true
       (dan tidak ada satu pun tautan kamera yang terbocor pada balasan itu);
     - akun PRO -> 111 kamera, kode tidak kembar, tautan berpola benar,
       daftar terurut menurut nomor kamera, koordinat masuk akal;
     - ADMIN dan ASS tetap boleh membuka walau tanpa langganan;
     - aksi=hidup -> memeriksa seluruh kamera, hasil disimpan
       (data/cctv_hidup.json), pemeriksaan kedua memakai simpanan (tidak
       memeriksa ulang) - hemat beban hosting dan kuota HP;
     - aksi=daftar sesudahnya menitipkan status hidup (0/1) pada setiap
       kamera, jadi aplikasi langsung dapat menampilkan lencana SIAP /
       TIDAK TERSEDIA;
     - aksi=uji&jumlah=5 memeriksa 5 kamera; aksi=uji&kode=... hanya kamera
       yang diminta; kode yang tidak dikenal -> 200 dengan 0 kamera;
     - aksi=segarkan saat situs Dishub tidak dapat dihubungi -> tetap 200 dan
       daftar lama dipakai (aplikasi tidak eror);
     - pelengkapan gambar otomatis dibatasi sekali setiap 6 jam (sudah diuji);
     - alamat gambar dirapikan menjadi pola situs Dishub (/poster/...);
     - berkas data tidak berubah saat aplikasi hanya membaca daftar.

   Pemeriksaan kode aplikasi (lib\cctv.dart & main.dart):
     - kurung seimbang / berkas utuh: YA;
     - 34 nama fungsi-warna-peta yang dipakai cctv.dart ADA semua definisinya;
     - 77 nama pada main.dart ADA semua definisinya.

   Catatan jujur: pengujian di dalam HP (memutar video, menggeser peta)
   harus Bapak lakukan sendiri, karena saya tidak dapat memasang aplikasi di
   HP Bapak. Bila ada yang tidak berjalan, kirim tangkapan layarnya - saya
   perbaiki.

==============================================================================
 2. MENGAMBIL DAFTAR SELURUH KAMERA (111 KAMERA)
==============================================================================

 Situs ATCS memakai API resmi berisi daftar seluruh kamera (nama, koordinat,
 gambar) untuk menampilkan halaman streaming mereka. Alat periksa_cctv.php
 mengambil daftar itu, lalu menyimpannya untuk dipakai aplikasi.

 CARA PAKAI (setelah periksa_cctv.php diunggah ke public_html):

    periksa_cctv.php                  keadaan hosting & petunjuk
    periksa_cctv.php?ambil=1          ambil daftar kamera dari API ATCS
    periksa_cctv.php?paksa=1&ambil=1  ambil ulang (memaksa, walau masih baru)
    periksa_cctv.php?uji=10           uji 10 tautan pertama (HIDUP / MATI)
    periksa_cctv.php?uji=semua        uji SELURUH tautan
    periksa_cctv.php?unduh=1          unduh data/cctv_medan.json

 HASIL
    data/cctv_medan.json  -> daftar kamera (kode, nomor, nama, alias, tautan,
                             koordinat). BERKAS INILAH yang nanti dibaca
                             aplikasi pada menu CCTV Online.

 KEUNTUNGAN CARA INI
    - Bapak tidak perlu menyusun daftar kamera satu per satu.
    - Bila Dishub menambah atau mengganti kamera, cukup buka
      periksa_cctv.php?paksa=1&ambil=1 -> daftar diperbarui, dan
      APLIKASI TIDAK PERLU DIBANGUN ULANG.
    - Alat ini juga menampilkan CONTOH DATA MENTAH dari API, supaya nama
      kolom (field) yang tersedia jelas terbaca bila suatu saat berubah.

 SUDAH DISIAPKAN JUGA (tidak wajib, hanya agar cepat)
    cctv_medan.json  -> daftar 111 kamera yang saya ambil dari sini.
      Bila ingin langsung memakainya tanpa menunggu hosting menyambung ke
      ATCS, buat folder "data" di dalam public_html lalu letakkan berkas ini
      di dalamnya dengan nama:  data/cctv_medan.json
    cctv_medan.m3u   -> daftar putar untuk mencoba semua kamera TANPA aplikasi:
      buka VLC -> Media -> Open Network Stream (Ctrl+N) -> pilih berkas ini.
