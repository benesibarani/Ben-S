 RTS PANEL BY BENE - PUTARAN 18H
 (MENU PROGRAM: INTRODEAL 2+1 / 1+1 / PAKET SENDIRI, BD TANPA PAKET,
  INPUT PROGRAM TANPA INTERNET, PETA + FILTER, BACKUP & SINKRON OFFLINE)
 CARA PASANG CEPAT  -  5 Oktober 2026
==============================================================================

 Paket ini untuk Bapak yang SUDAH pernah memasang RTS_PANEL_PUTARAN_18G.zip.
 Isinya hanya berkas yang BARU atau BERUBAH untuk revisi menu "Program".

 LIMA PERUBAHAN PUTARAN 18H
 --------------------------
   1. INTRODEAL = PROGRAM PAKET. Di dalamnya ada pilihan paket:
         2+1 (bawaan)      -> Beli 2 gratis 1
         1+1 (bawaan)      -> Beli 1 gratis 1
         PAKET SENDIRI     -> Sales membuat sendiri, contoh 3+1
      Paket bawaan tidak dapat dihapus; paket buatan Sales dapat dihapus.
      Produk diambil dari MENU BARANG BAWAAN (atau SINKRON ONLINE).
   2. BD = NEW BRAND DISTRIBUTION -> TIDAK memakai paket, hanya PRODUK
      (produknya sudah ada di outlet).
   3. INPUT OFFLINE: tombol CATAT PROGRAM menyimpan catatan program ke
      DALAM HP (tanpa internet). Catatan dikirim ke server lewat tombol
      CATATAN TERSIMPAN -> KIRIM KE SERVER. Ada lencana angka di kanan atas.
   4. PETA & FILTER: peta OpenStreetMap + penyaring INTRODEAL / BD,
      penyaring KUNJUNGAN (sudah/belum), dan penyaring HARI (Senin-Minggu).
      Peta kecil juga TERLAMPIR di dalam form CATAT PROGRAM.
   5. MENU PRO BARU: "Backup & Sinkron Data Offline" -> melihat DATA DI HP
      (kunjungan, nota, input program, piutang, dll), berapa yang belum
      dikirim, tombol salin ringkasan, tandai sudah dikirim, dan buat
      cadangan .db di dalam HP.

 LANGKAH 1 - DI HOSTING (cPanel)
 -------------------------------
   1. Buka File Manager -> public_html -> folder api
   2. Unggah  api/program.php  (pilih TIMPA bila ditanya)
   3. Buka phpMyAdmin -> pilih database Bapak -> menu SQL
      Tempel SELURUH isi RTS_PANEL_PROGRAM.sql, lalu tekan GO.
      Perintah ini hanya MEMBUAT 3 tabel baru:
         rts_program_produk, rts_program_paket, rts_program_input
      dan mengisi paket bawaan 2+1 dan 1+1. TIDAK ada data lama dihapus.
      (Disarankan Backup dulu database - cukup tekan Ekspor di phpMyAdmin.)
   4. Tidak ada berkas hosting lain yang berubah pada putaran ini.

 LANGKAH 2 - DI KOMPUTER (proyek Flutter D:\Project\rts_panel_app)
 ----------------------------------------------------------------
   1. Ekstrak paket ini ke mana saja (misalnya Desktop), pilih TIMPA semua.
   2. Klik kanan  LANGKAH1_PASANG_SEMUA.ps1  ->  Run with PowerShell
      (skrip menyalin program.dart, kasir_lokal.dart, main.dart, dan
       pubspec.yaml ke proyek Bapak; berkas lama dicadangkan dulu)
   3. Buka terminal di folder proyek, jalankan berurutan:
          flutter clean
          flutter pub get
          flutter analyze
          flutter build apk --release
   4. Bila muncul peringatan kuning pada menu Program, kirimkan tulisannya
      ke saya - akan saya perbaiki sampai bersih.

 LANGKAH 3 - DI HP
 -----------------
   1. Pasang APK baru dengan cara MENIMPA. JANGAN hapus aplikasi lama
      (data Kasir, STRUK POM, dan catatan program di HP tetap aman).
   2. Buka aplikasi -> Menu PRO.
      Sekarang ada: Program Introdeal, Program BD, Input Program,
      Peta & Filter Program, dan Backup & Sinkron Data Offline.
   3. Program Introdeal -> pilih paket 2+1 atau 1+1 (atau buat PAKET SENDIRI).
   4. Tekan PILIH TOKO TERDEKAT, lalu CATAT PROGRAM - boleh tanpa internet.

 PEMERIKSAAN SESUDAH PASANG
 --------------------------
   Di komputer: jalankan .\PERIKSA_KODE_APLIKASI.ps1
       harus tertulis kode aplikasi  RTS-2026-10-05-18H
   Di aplikasi: Menu PRO -> Program Introdeal
       harus terlihat paket 2+1 dan 1+1, dan tombol PAKET SENDIRI.
   Bila tertulis "tabel belum ada": tekan SINKRON ONLINE di menu Program,
       lalu tempel perintah SQL yang muncul ke phpMyAdmin.
