 PERUBAHAN PUTARAN 18K
 ---------------------
   1. RUTE PLAN LAYAR PENUH.
      Peta memenuhi seluruh layar. Di bagian atas ada bilah berisi tombol
      kembali, judul "Rute Plan - N toko", dan tombol kantor. Di sisi kanan
      ada tombol lokasi saya, lihat semua titik, zoom +, zoom -, dan PENSIL.
   2. SIDEBAR "MENU RUTE PLAN" YANG BISA DIGESER.
      Sidebar melayang di atas peta. Bagian judulnya dapat diseret ke mana
      saja, dapat dilipat, dan berisi menu: Filter & Sales District, List
      Customer, Copy Urutan (teks), Daftar Lengkap, Buka Rute di Google Maps,
      Pensil Garis, Garis Tersimpan, Warna nomor, Muat Kantor, Lokasi Saya,
      dan Lihat Semua Titik.
   3. NOMOR URUT + KARTU NAMA DAN ID CUSTOMER.
      Setiap titik customer bernomor. Ketuk nomor -> kartu muncul dengan
      NAMA dan ID CUSTOMER. Nomor bisa diubah (tombol - / +, atau UBAH
      NOMOR). Daftar, nomor di peta, dan kartu ikut berubah.
   4. PENSIL MEMBUAT GARIS ANTAR CUSTOMER.
      Ketuk nomor toko secara berurutan, lalu SIMPAN GARIS. Garis disimpan
      di HP. Garis TIDAK dibuat otomatis.
   5. PENANDA VERSI baru: RTS-2026-10-09-18K, pubspec 1.5.5+20.

 LANGKAH 1 - DI HOSTING (cPanel)
 -------------------------------
   TIDAK ADA yang perlu diunggah pada putaran ini.

 LANGKAH 2 - DI KOMPUTER (proyek Flutter D:\Project\rts_panel_app)
 ----------------------------------------------------------------
   1. Ekstrak paket ini ke mana saja (misalnya Desktop), pilih TIMPA semua.
   2. Klik kanan  LANGKAH1_PASANG_SEMUA.ps1  ->  Run with PowerShell
      (skrip ini menimpa main.dart ke DUA tempat: akar folder dan lib\main.dart)
   3. Buka terminal di folder proyek, jalankan berurutan:
          flutter clean
          flutter pub get
          flutter analyze
          flutter build apk --release

   Cara membaca hasil "flutter analyze":
     - Tanda MERAH (error)   : harus NOL. Bila ada, kirim pesan lengkapnya.
     - Tanda KUNING (warning): sebaiknya NOL sebelum rilis.
     - Pesan BIRU (info)     : boleh diabaikan.
     - Pesan peringatan dari Gradle BUKAN galat. Yang diperiksa hanya Error.

 LANGKAH 3 - DI HP
 -----------------
   1. Pasang APK baru dengan cara MENIMPA. JANGAN hapus aplikasi lama.
   2. Buka MENU PRO -> RUTE PLAN. Peta tampil penuh, sidebar MENU RUTE PLAN
      ada di atas peta.
   3. Di sidebar, ketuk Filter & Sales District untuk memilih hari,
      frekuensi, dan district. Pilihan ini disimpan di HP.
   4. Ketuk nomor toko di peta untuk melihat NAMA dan ID CUSTOMER.
   5. Tekan tombol PENSIL di kanan peta. Ketuk dua nomor toko berurutan,
      lalu tekan SIMPAN GARIS. Tekan SELESAI MENGGAMBAR untuk keluar.
