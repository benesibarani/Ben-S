Kemudian, di bagian PALING BAWAH berkas (setelah blok android { } ditutup),

--------------------------------------------------------------------------------
CATATAN PENTING
--------------------------------------------------------------------------------

1. Tanda (+) HANYA penanda pada panduan ini. JANGAN ikut disalin.

2. Bila di dalam blok android { } sudah ada compileOptions, cukup tambahkan
   baris coreLibraryDesugaringEnabled / isCoreLibraryDesugaringEnabled di
   dalamnya. Jangan membuat blok kedua dengan nama yang sama.

3. Bila sourceCompatibility / targetCompatibility sudah ada dengan nilai 1.8
   atau 11, boleh diganti menjadi VERSION_17 / JavaVersion.VERSION_17.

4. Bila di bagian bawah berkas sudah ada blok dependencies, cukup tambahkan
   satu baris coreLibraryDesugaring di dalamnya.

5. Setelah selesai menyimpan, jalankan:

       cd D:\Project\rts_panel_app
       flutter pub get
       flutter run


--------------------------------------------------------------------------------
BILA BUILD MASIH GAGAL
--------------------------------------------------------------------------------

Pesan "requires core library desugaring to be enabled"
  -> pengaturan LANGKAH 2 belum masuk dengan benar, atau berkas yang diedit
     bukan berkas yang dipakai (periksa ada tidaknya akhiran .kts).

Pesan "coreLibraryDesugaring" tidak dikenali
  -> Anda memakai sintaks Groovy pada berkas Kotlin DSL, atau sebaliknya.
     Periksa kembali LANGKAH 1.

Build gagal dengan keluhan cache Gradle
  -> jalankan berurutan:

       cd D:\Project\rts_panel_app
       flutter clean
       rmdir /s /q android\.gradle
       cd android
       gradlew.bat --stop
       cd ..
       flutter pub get
       flutter run

Bila tetap gagal dan Anda ingin kembali ke keadaan sebelumnya:
  1. Hapus dua baris ini pada pubspec.yaml:
         flutter_local_notifications: ^19.0.0
         workmanager: ^0.9.0
  2. Kembalikan android/app/build.gradle (atau .kts) seperti semula
  3. Jalankan flutter pub get, lalu flutter run
  Aplikasi akan kembali normal tanpa fitur pemberitahuan HP. Seluruh fitur
  lain (Master Customer, Pengajuan, Ingat saya) tidak terpengaruh.
