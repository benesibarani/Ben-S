==============================================================================
 RTS PANEL BY BENE - PEMBARUAN LANGSUNG DI DALAM APLIKASI
 (unduh + pasang TANPA membuka Chrome)
==============================================================================

 PERTANYAAN BAPAK
 ----------------
 "Kalau update tidak bisa ya mulai mendownload, loading dan penginstalan
  tidak bisa langsung di aplikasinya. Ini kan biasa harus dari Google Chrome
  proses downloadnya. Kalau semua langsung dari aplikasi apakah bisa?
  Ketika muncul notice Update, dan di klik update maka muncul loading."

 JAWABAN
 -------
   BISA. Seluruh proses dapat dikerjakan oleh aplikasi sendiri:
       notifikasi UPDATE  ->  unduh di dalam aplikasi  ->  layar Pasang
   Tanpa membuka Chrome sama sekali, tanpa mencari berkas di folder Unduhan.

   Sebelumnya aplikasi MEMANG hanya dapat MEMBUKA TAUTAN unduhan; yang
   mengunduh adalah Chrome. Berkasnya tersimpan di folder unduhan Chrome,
   sehingga petugas harus: buka Chrome - tunggu - buka daftar unduhan -
   ketuk berkas - tekan Pasang. Belum lagi Chrome kadang menampilkan
   peringatan "berkas ini dapat membahayakan perangkat".

   Sesudah perubahan ini, alurnya menjadi:
       1. Notifikasi "Versi Baru RTS Panel Tersedia" muncul di layar HP
       2. Ketuk notifikasi -> muncul kotak pembaruan -> tekan PERBARUI SEKARANG
       3. Aplikasi mengunduh sendiri - ada bilah kemajuan (persen) pada kotak
          aplikasi DAN pada pemberitahuan Android
       4. Begitu selesai, layar "Pasang" Android terbuka SENDIRI
          (walaupun kotak kemajuan sudah ditutup petugas)
       5. Tekan PASANG satu kali
       6. Selesai. Aplikasi berusaha membuka dirinya sendiri; bila Android
          menolak, muncul pemberitahuan "Pembaruan RTS Panel Selesai" yang
          dapat ditekan - atau tombol BUKA pada layar pemasangan.
          Data lama tetap utuh (petugas tidak perlu masuk ulang).

 SEBERAPA OTOMATIS? (PERTANYAAN BAPAK)
 -------------------------------------
   Bagian                     | Otomatis?  | Keterangan
   ---------------------------|------------|--------------------------------
   Menampilkan pemberitahuan  | YA         | dari FCM, walau aplikasi ditutup
   Mengunduh berkas           | YA         | di dalam aplikasi, ada kemajuan
   Menampilkan kemajuan       | YA         | persen + bilah pada pemberitahuan
   Membuka layar Pasang       | YA         | terbuka sendiri sesudah unduhan
   Menekan tombol PASANG      | TIDAK      | wajib sekali ketuk (aturan Android)
   Membuka aplikasi sesudah   | DICOBA     | berhasil pada banyak HP; bila
   pemasangan selesai         |            | ditolak -> tekan pemberitahuan/memori

   Mengapa tombol PASANG tidak dapat dilewati?
   Android sejak versi 8 mewajibkan persetujuan pengguna setiap kali ada
   aplikasi yang dipasang dari luar toko aplikasi. Tujuannya melindungi HP
   dari aplikasi palsu. Tidak ada aplikasi biasa yang dapat melewatinya -
   dan sebaiknya memang begitu.

   SATU-SATUNYA cara agar pemasangan benar-benar tanpa sentuhan adalah
   mendaftarkan HP-HP petugas sebagai perangkat yang DIKELOLA PERUSAHAAN
   (Android Enterprise / device owner, biasanya lewat aplikasi MDM). Dengan
   keadaan itu, sistem mengizinkan pemasangan tanpa layar konfirmasi. Ini
   memerlukan penyiapan pada setiap HP (paling mudah sebelum HP dipakai, atau
   lewat penyetelan ulang pabrik) - beri tahu saya bila Bapak ingin menempuh
   cara ini, akan saya siapkan langkahnya.

 BAGIAN 1 - CARA MEMASANG (2 BERKAS BARU + 1 BERKAS DIUBAH)
==============================================================================

 Paling mudah: jalankan LANGKAH1_PASANG_SEMUA.ps1 dari paket
 RTS_PANEL_PUTARAN_7.zip - langkah 4b menangani ketiga berkas di bawah ini
 secara otomatis (termasuk menyalin ke folder yang benar).

 Bila Bapak ingin memasang sendiri, ini berkasnya:

   [ ] 1. MainActivity.kt
          Dari : 2_APLIKASI_copy_ke_proyek\MainActivity.kt
          Ke   : D:\Project\rts_panel_app\android\app\src\main\kotlin\
                    com\example\rts_panel_app\MainActivity.kt
          (Timpa berkas MainActivity.kt yang sudah ada - ganti seluruh isinya.
           Bila folder itu berbeda, cari berkas bernama MainActivity.kt di
           dalam folder android\app\src\main - itulah tempatnya.)

   [ ] 2. file_paths.xml
          Dari : 2_APLIKASI_copy_ke_proyek\file_paths.xml
          Ke   : D:\Project\rts_panel_app\android\app\src\main\res\xml\file_paths.xml
          (Bila folder "xml" belum ada di dalam folder "res", buat dulu
           foldernya - huruf kecil semua.)

   [ ] 2b. RtsPenerimaPembaruan.kt  (BARU)
          Dari : 2_APLIKASI_copy_ke_proyek\RtsPenerimaPembaruan.kt
          Ke   : D:\Project\rts_panel_app\android\app\src\main\kotlin\
                    com\example\rts_panel_app\RtsPenerimaPembaruan.kt
          (Satu folder dengan MainActivity.kt. Isinya membuat aplikasi
           berusaha terbuka sendiri sesudah pembaruan terpasang.)

   [ ] 3. AndroidManifest.xml - TAMBAHKAN 3 bagian
          (3a) Izin, diletakkan DI ATAS baris <application>:

                <uses-permission android:name="android.permission.REQUEST_INSTALL_PACKAGES" />

          (3b) Pembagi berkas, diletakkan DI DALAM <application> ... </application>:

                <provider
                    android:name="androidx.core.content.FileProvider"
                    android:authorities="${applicationId}.rtsberkas"
                    android:exported="false"
                    android:grantUriPermissions="true">
                    <meta-data
                        android:name="android.support.FILE_PROVIDER_PATHS"
                        android:resource="@xml/file_paths" />
                </provider>

          (3c) Pembuka aplikasi sesudah pembaruan, diletakkan DI DALAM
               <application> ... </application> (misalnya sesudah <provider>):

                <receiver
                    android:name=".RtsPenerimaPembaruan"
                    android:exported="true"
                    android:enabled="true">
                    <intent-filter>
                        <action android:name="android.intent.action.MY_PACKAGE_REPLACED" />
                    </intent-filter>
                </receiver>

          Tulis ${applicationId} apa adanya (jangan diganti) - Android sendiri
          yang mengisinya dengan nama paket aplikasi Bapak.
          Contoh susunan lengkapnya ada pada android_manifest_tambahan.xml.

   [ ] 4. main.dart (versi baru, penanda RTS-2026-10-01-9) - seperti biasa
          Ke   : D:\Project\rts_panel_app\lib\main.dart

   [ ] 5. Setelah semua tersalin:
              cd D:\Project\rts_panel_app
              flutter clean
              flutter pub get
              flutter run -d CPH1937

 Perubahan ini hanya di sisi ANDROID (Kotlin), jadi TIDAK menambah paket
 baru pada pubspec.yaml - tidak perlu menunggu unduhan paket tambahan.
 Bila Gradle mengeluh "Unresolved reference: FileProvider", tambahkan satu
 baris di android\app\build.gradle.kts pada bagian dependencies:

     implementation("androidx.core:core-ktx:1.13.1")

 BAGIAN 2 - APA YANG DILIHAT PETUGAS
==============================================================================

   [ ] 1. Pemberitahuan pembaruan muncul (tetap seperti sebelumnya, dari FCM).
          Pada pemberitahuan ada tombol UPDATE.

   [ ] 2. Menekan tombol UPDATE membuka aplikasi, lalu tampil kotak
          "Pembaruan Tersedia" berisi versi, ukuran berkas, dan catatan
          pembaruan. Tekan PERBARUI SEKARANG.

   [ ] 3. Muncul kotak "Mengunduh Pembaruan" dengan bilah kemajuan + persen.
             - Unduhan berjalan walau layar HP dimatikan.
             - Petugas boleh menekan SEMBUNYIKAN; unduhan tetap berjalan,
               dan dapat dipantau dari pemberitahuan "Pembaruan RTS Panel"
               pada layar HP.
             - Bila sambungan internet terputus, unduhan menunggu sambungan
               kembali (tidak mengulang dari nol).

   [ ] 4. Sesudah selesai, layar Pasang Android terbuka SENDIRI.
          Tekan PASANG. Aplikasi lama DIPERBARUI (bukan dipasang dua kali),
          karena nama paketnya tidak diubah - jadi tidak ada data yang hilang
          dan petugas tidak perlu masuk ulang.

   [ ] 5. Selesai dipasang, aplikasi berusaha terbuka sendiri (berkas
          RtsPenerimaPembaruan.kt). Bila Android menolak, tersedia:
             - tombol BUKA pada layar pemasangan, atau
             - pemberitahuan "Pembaruan RTS Panel Selesai" pada layar HP.

 SEKALI SAJA - IZIN PEMASANGAN
   Android 8 ke atas mewajibkan izin "Instal aplikasi tidak dikenal" untuk
   aplikasi yang memasang APK. Pada pemasangan pertama, aplikasi menampilkan
   kotak "Satu Kali Pengaturan":

        [ UNDUH LEWAT CHROME ]     [ BUKA PENGATURAN ]

   Tekan BUKA PENGATURAN -> hidupkan izin untuk RTS Panel -> kembali ke
   aplikasi -> tekan PERBARUI SEKARANG lagi.
   BERKASNYA SUDAH TERUNDUH pada keadaan ini, jadi tidak menunggu lama.
   Setelah itu, pembaruan berikutnya berjalan sendiri tanpa pertanyaan lagi.

   Bila petugas tidak ingin mengurus izin, tombol UNDUH LEWAT CHROME tetap
   disediakan - jadi pembaruan tidak pernah gagal total.
   Di aplikasi, izin itu juga dapat dihidupkan lebih dahulu lewat:
        Pengaturan HP -> Aplikasi -> RTS Panel -> Instal aplikasi tidak dikenal


==============================================================================
 BAGIAN 3 - YANG BELUM BERUBAH (DAN SEBABNYA)
==============================================================================

   Pemasangan APK baru TIDAK dapat dikerjakan sepenuhnya tanpa persetujuan
   pengguna. Ini aturan Android (sejak versi 8), bukan kekurangan aplikasi:
   Android WAJIB menampilkan layar "Pasang" yang harus ditekan sekali.
   Aplikasi sekarang sudah mengantarkan sampai layar itu terbuka sendiri -
   itulah batas terjauh yang diizinkan Android.

   Sesudah aplikasi sudah memasang pembaruan sekali dan izin pemasangan
   diberikan, prosesnya menjadi: ketuk notifikasi -> PERBARUI SEKARANG ->
   tunggu -> PASANG. Tiga sentuhan, tanpa Chrome.


==============================================================================
 BAGIAN 4 - BILA ADA MASALAH
==============================================================================

 Kotak pembaruan langsung membuka Chrome, tidak ada bilah kemajuan
   -> Berkas MainActivity.kt belum terpasang. Ulangi BAGIAN 1 langkah 1,
      lalu JUMPA: flutter clean -> flutter pub get -> flutter run lagi.
   -> Ini "aman gagal": aplikasi memakai cara lama, sehingga pembaruan tidak
      pernah gagal total.

 Muncul pesan "Satu Kali Pengaturan" berulang kali
   -> Izin pemasangan belum dihidupkan. Pengaturan HP -> Aplikasi ->
      RTS Panel -> Instal aplikasi tidak dikenal -> hidupkan.

 Muncul "Unduhan gagal ... periksa sambungan internet"
   -> Ketuk PERBARUI SEKARANG lagi. Sebab tersering: sambungan putus.
   -> Bila tertulis "Server menolak permintaan unduhan (berkas tidak
      ditemukan)", berarti berkas APK di folder apk/ sudah dihapus atau
      namanya diubah. Periksa pada halaman app_versi.php.

 Muncul "Penyimpanan HP tidak cukup"
   -> Kosongkan penyimpanan HP (berkas APK sekitar 25-55 MB).

 Gagal menyusun aplikasi (build) setelah memasang berkas ini
   -> Periksa nama folder MainActivity.kt. Tempat paling aman: di dalam
      folder android\app\src\main\kotlin\com\example\rts_panel_app\
   -> Bila muncul "Unresolved reference: FileProvider", tambahkan baris
      implementation("androidx.core:core-ktx:1.13.1") pada dependencies.
   -> Bila ragu, kembalikan saja MainActivity.kt dari berkas cadangan
      (berkas .lama_<tanggal> yang dibuat LANGKAH1) - aplikasi tetap dapat
      dibangun dan pembaruan memakai cara lama (Chrome).

 Aplikasi terpasang dua kali / muncul dua ikon
   -> Pastikan applicationId TIDAK diubah (tetap com.example.rts_panel_app).
      Inilah sebabnya berkas ini tidak menyentuh applicationId.
