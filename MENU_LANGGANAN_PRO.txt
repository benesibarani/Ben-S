==============================================================================
 RTS PANEL BY BENE - MENU "LANGGANAN PRO" PADA SIDEBAR (KHUSUS ADMIN)
==============================================================================

 PERMINTAAN BAPAK
 ----------------
 "Pada menu sidebar untuk role Admin tidak ada menu untuk melihat status Pro
  atau gratis User. Mengedit Harga Pro dan durasinya. Tolong buatkan menunya."

 SUDAH DIKERJAKAN
 ----------------
 Kini pada sidebar bagian ADMINISTRASI ada menu baru:

        Kelola User
        Langganan PRO        <-- MENU BARU (mahkota)
        Versi Aplikasi

 Menu ini HANYA tampil untuk role ADMIN. Halaman yang dibuka adalah
 langganan_admin.php, yang isinya:

   1. Ringkasan jumlah akun:  PRO AKTIF | UJI COBA | GRATIS | PERNAH PRO KINI
      GRATIS | BAYAR MENUNGGU
   2. Daftar seluruh pengguna + lencana status PRO / GRATIS, tanggal berlaku,
      sisa hari, dan tombol tindakan:  +30 HARI | +90 HARI | TRIAL | HENTIKAN
   3. Kotak pencarian (nama / username / role / email) + penyaring status
      (Semua status / Hanya PRO / Hanya uji coba / Hanya GRATIS)
   4. Pernyataan pembayaran QRIS dari aplikasi: tombol SETUJUI / TOLAK
   5. KARTU BARU: Pengaturan Harga & Durasi Langganan PRO
   6. Unggah gambar QRIS + tombol PERBARUI DATABASE

 Lencana merah pada menu sidebar = jumlah pernyataan "SAYA SUDAH BAYAR" yang
 belum Bapak periksa. Jadi Bapak langsung tahu ada pembayaran menunggu tanpa
 harus membuka halaman Akun PRO.


==============================================================================
 BAGIAN 0 - AKUN SALES MASIH TERKUNCI SESUDAH TOP UP? (SUDAH DIPERBAIKI)
==============================================================================

 Kejadian yang Bapak laporkan:
   "User sales sudah top up dan ADMIN sudah setujui, tetapi status akun sales
    tetap terkunci untuk fitur PRO-nya."

 Ada DUA sebab, dan keduanya SUDAH DIPERBAIKI pada putaran ini
 (versi aplikasi 1.2.6, kode 9, penanda RTS-2026-10-03-14).

 SEBAB 1 - DI APLIKASI: jawaban lama disimpan terlalu lama
 ------------------------------------------------------------------------
 Aplikasi memeriksa hak PRO ke server, lalu MENYIMPAN jawabannya di dalam HP
 supaya kasir tetap jalan tanpa internet. Sebelumnya jawaban "belum boleh"
 (GRATIS) dianggap masih berlaku sampai 6 JAM. Akibatnya, walaupun pembayaran
 sudah disetujui ADMIN, menu PRO tetap terkunci sampai 6 jam berlalu.

 Sesudah diperbaiki:
   - jawaban "belum boleh" hanya berlaku 3 MENIT, lalu aplikasi memeriksa
     ulang sendiri ke server;
   - jawaban "boleh" tetap 6 jam (supaya kasir tetap jalan tanpa internet);
   - status juga diperiksa ulang setiap aplikasi dibuka dan setiap kembali
     dari latar belakang - jadi cukup keluar dari aplikasi lalu masuk lagi.

 SEBAB 2 - DI SERVER: penanda akun_pro belum ada di database
 ------------------------------------------------------------------------
 Sebelumnya akun dianggap PRO hanya bila kolom penanda `akun_pro` bernilai 1.
 Bila kolom itu belum ada pada tabel sales_users, pembayaran yang disetujui
 tetap terbaca GRATIS.

 Sesudah diperbaiki (api/langganan_inti.php):
   - tanggal `pro_selesai` SENDIRI sudah cukup untuk menjadikan akun PRO,
     jadi pembayaran yang sudah disetujui ADMIN langsung membuka fitur PRO;
   - tombol PERBARUI DATABASE pada halaman ini tetap dianjurkan ditekan sekali
     supaya seluruh kolom langganan (`akun_pro`, `pro_mulai`, `pro_selesai`,
     `trial_mulai`, `trial_selesai`, `foto_profil`) tersedia di database.

 BAGIAN 0A - DATABASE SUDAH PRO, TETAPI MENU PRO MASIH TERKUNCI
 ------------------------------------------------------------------------
 Kejadian: pada tabel sales_users baris user tersebut sudah
 `akun_pro = 1` dengan `pro_mulai` dan `pro_selesai` terisi (PRO selesai
 2027-01-11), status di aplikasi pun tampak PRO, TETAPI ketika kartu menu
 PRO ditekan tetap muncul tawaran langganan / halaman terkunci.

 Sebabnya: jawaban lama "belum boleh" (dari masa akun masih GRATIS atau masa
 uji coba sudah habis) masih tersimpan di dalam HP dan dipakai lebih dahulu
 daripada data akun terbaru dari server.

 Penawar yang sudah dipasang pada versi 1.2.7 (kode 10, penanda
 RTS-2026-10-03-15):
   1. DATA AKUN DARI SERVER MENJADI BUKTI PRO DI DALAM HP.
      Bila `akun_pro` = 1 pada data akun (hasil login / session_check), maka
      seluruh fitur PRO langsung dibolehkan, tanpa memakai jawaban lama.
      (lib/kasir_lokal.dart - proSesi)
   2. SETIAP KARTU MENU PRO YANG DITEKAN MEMERIKSA ULANG KE SERVER.
      Bila jawaban di HP masih "belum boleh", aplikasi bertanya langsung ke
      server (session_check.php). Begitu server menyatakan PRO, kartu itu
      LANGSUNG TERBUKA tanpa keluar aplikasi.
      (main.dart - RtsAkunSegar + _bolehPro)
   3. Status diperiksa otomatis saat aplikasi dibuka dan kembali dari latar
      belakang, serta lewat tombol SINKRON AKUN pada menu Sinkronisasi.

 URUTAN PEMASANGAN YANG BENAR (3 langkah, jangan dibalik):
   A. Unggah api/langganan_inti.php ke public_html/api, lalu di
      langganan_admin.php tekan PERBARUI DATABASE sekali.
   B. Di komputer: ekstrak RTS_PANEL_PUTARAN_14.zip, jalankan
      .\LANGKAH1_PASANG_SEMUA.ps1, lalu flutter clean -> flutter pub get.
   C. Bangun + pasang ke HP:  flutter run -d CPH1937
      Penting: aplikasi di HP HARUS versi baru. Periksa pada halaman
      Pengaturan - penanda kode harus RTS-2026-10-03-15. Selama HP masih
      memakai aplikasi lama, perbaikan ini belum ikut terpasang.

 BAGIAN 0B - TOMBOL BARU "SINKRON AKUN" (menu Sinkronisasi di aplikasi)
 ------------------------------------------------------------------------
 Menu UTAMA -> Sinkronisasi kini memuat KARTU STATUS AKUN di bagian paling
 atas:

     Status Akun                                     [ PRO / GRATIS ]
     Berlaku sampai 02-11-2026 (sisa 30 hari)
     [ SINKRON AKUN ]

 Menekan SINKRON AKUN membuat aplikasi:
   1. membaca ulang keadaan langganan dari server (langganan.php),
   2. memperbarui data akun pada sesi (session_check.php),
   3. menyegarkan izin PRO yang tersimpan di dalam HP,
   4. menampilkan hasilnya, misalnya:
        "Akun PRO AKTIF sampai 02-11-2026 (sisa 30 hari). Seluruh menu PRO
         sudah dapat dibuka."
   5. menghilangkan kunci pada kartu menu PRO tanpa perlu memasang ulang.

 Tombol SINKRONKAN SEKARANG pada halaman yang sama juga ikut menyegarkan
 status akun, jadi tombol mana saja dapat dipakai.

 LANGKAH PEMASANGAN PUTARAN INI
 ------------------------------------------------------------------------
   1. Unggah  api\langganan_inti.php  (beserta berkas server lain pada paket)
      ke folder public_html/api.
   2. Buka https://rts.benedic-s.com/langganan_admin.php, tekan
      PERBARUI DATABASE sekali.
   3. Di komputer: ekstrak paket, jalankan .\LANGKAH1_PASANG_SEMUA.ps1,
      lalu flutter clean -> flutter pub get -> flutter run -d CPH1937.
   4. Di HP sales: buka menu Sinkronisasi -> tekan SINKRON AKUN. Bila
      pembayarannya sudah disetujui ADMIN, status langsung berubah PRO.

 CARA MEMERIKSA BAHWA PEMBAYARAN BENAR-BENAR SUDAH DISETUJUI
 ------------------------------------------------------------------------
   - Buka langganan_admin.php. Pada baris user tersebut harus tampil lencana
     PRO beserta tanggal berlakunya (bukan GRATIS).
   - Bila pernyataan pembayarannya masih ada pada daftar "Pernyataan
     pembayaran QRIS", berarti tombol SETUJUI belum ditekan.
   - Pada aplikasi sales: Sinkronisasi -> SINKRON AKUN. Bila jawabannya
     "Status akun di server masih GRATIS", berarti langkah ADMIN di atas
     belum selesai.

==============================================================================
 BAGIAN 2 - CARA MELIHAT STATUS PRO / GRATIS SETIAP USER
==============================================================================

   [ ] 1. Masuk sebagai ADMIN
   [ ] 2. Klik menu "Langganan PRO" pada sidebar
   [ ] 3. Kartu "Ringkasan Status Akun" menampilkan jumlahnya sekilas
   [ ] 4. Kartu "Daftar Akun - Status PRO / GRATIS" menampilkan tiap pengguna:

           PRO      (hijau)  - bebas iklan, masih berlaku
           PRO      (hijau)  - bila tanpa batas waktu: "tanpa batas waktu"
           UJI COBA (kuning) - masih memakai masa uji coba
           GRATIS   (merah)  - melihat iklan

         Kolom "Berlaku sampai" dan "Sisa" menunjukkan tanggal & sisa harinya.

   [ ] 5. Ingin cepat? Isi kotak cari (misalnya nama petugas) lalu tekan CARI,
          atau pilih "Hanya PRO" / "Hanya GRATIS" pada pilihan status.

 Mengubah status langsung dari halaman ini (tanpa perlu membuka aplikasi HP):
   +30 HARI   -> menambah masa PRO (angka 30 mengikuti pengaturan di Bagian 3)
   +90 HARI   -> menambah masa PRO 3 bulan
   TRIAL      -> memulai/memulihkan uji coba (hanya muncul bila masih tersedia)
   HENTIKAN   -> akun kembali GRATIS, iklan tampil lagi


==============================================================================
 BAGIAN 3 - CARA MENGEDIT HARGA PRO DAN DURASINYA
==============================================================================

   [ ] 1. Buka halaman "Langganan PRO"
   [ ] 2. Cari kartu "Pengaturan Harga & Durasi Langganan PRO"
   [ ] 3. Isi ketiga angka:

           Harga langganan (rupiah) : 1000 - 1.000.000   (contoh: 5000)
           Lama masa PRO (hari)     : 1 - 365            (contoh: 30)
           Lama uji coba (hari)     : 0 - 90             (0 = dimatikan)

   [ ] 4. Tekan "SIMPAN PENGATURAN"
   [ ] 5. Muncul tulisan hijau: "Pengaturan tersimpan. Harga Rp5.000 - masa
          PRO 30 hari - uji coba 7 hari. Aplikasi dan website langsung memakai
          nilai baru ini."

 Tombol "KEMBALIKAN KE BAWAAN" mengembalikan: Rp5.000 / 30 hari / 7 hari.

 NILAI BARU LANGSUNG DIPAKAI DI MANA SAJA
   - Harga      : tampil pada halaman Langganan PRO di aplikasi HP
   - Lama PRO   : tombol "+N HARI", penyetujuan pembayaran QRIS, dan
                  pemberian masa PRO dari aplikasi ADMIN
   - Uji coba   : lama masa uji coba untuk petugas yang baru masuk

 PENTING - aplikasi TIDAK perlu dibangun ulang (tidak perlu build APK baru)
 bila harga/durasi berubah, sebab aplikasi membaca angka ini dari server
 setiap kali halaman Langganan PRO dibuka. Jadi Bapak bebas mengubah harga
 kapan pun.

 Catatan: pembayaran yang SUDAH menunggu (status MENUNGGU) memakai lama hari
 yang tercatat saat petugas menekan "SAYA SUDAH BAYAR". Pembayaran baru
 mengikuti angka terbaru.

 Tempat penyimpanan: tabel baru rts_lg_pengaturan pada database (kolom kunci,
 nilai, diperbarui). Tabel dibuat otomatis saat pertama kali menekan SIMPAN
 PENGATURAN, atau lewat tombol PERBARUI DATABASE. Tidak perlu phpMyAdmin.

==============================================================================
 BAGIAN 5 - BILA MUNCUL "HTTP ERROR 500" (SUDAH DIPERBAIKI)
==============================================================================

 Apa yang terjadi
   Halaman langganan_admin.php sempat berbunyi "This page isn't working -
   HTTP ERROR 500". Sebabnya BUKAN pada halaman itu sendiri, melainkan pada
   berkas api/langganan_inti.php versi 2 yang saya kirim lebih dahulu:

     Di dalamnya ada baris pembuat tabel:
         nilai VARCHAR(190) NOT NULL DEFAULT ''     <-- memakai ' (kutip tunggal)
     pada PHP tanda kutip tunggal di dalam kutip tunggal harus ditulis \'
     (garis miring + kutip). Karena garis miringnya hilang, kalimat PHP-nya
     terputus dan PHP menghentikan seluruh halaman -> HTTP ERROR 500.

   Akibat berantai: SEMUA berkas yang memuat berkas inti itu ikut gagal,
   termasuk api/login.php dan api/session_check.php - jadi aplikasi Android
   pun dapat gagal masuk. Karena itu berkas inti yang baru WAJIB diunggah.

 Sudah diperbaiki
   - api/langganan_inti.php : baris itu kini memakai tanda kutip ganda,
     sehingga tidak ada lagi tanda kutip yang perlu dilindungi.
     Ukuran berkas yang benar: 28.819 bita (877 baris).
   - langganan_admin.php versi 3 : ditambah pengaman. Sebelum berkas inti
     dimuat, halaman memeriksa dulu apakah berkas itu utuh (ukurannya dan
     pasangan tanda kurungnya). Bila tidak utuh, yang tampil bukan halaman
     500 yang kosong, melainkan keterangan + cara memperbaikinya.
   - Ditambah penangkap galat PHP (khusus ADMIN): bila di kemudian hari ada
     galat PHP yang fatal, halaman menampilkan tulisan galatnya sehingga dapat
     Bapak kirimkan kepada saya.

 Yang perlu Bapak lakukan sekarang
   [ ] 1. Unggah ULANG dua berkas dari paket RTS_PANEL_PUTARAN_7.zip:
            api/langganan_inti.php   -> ke folder api/     (WAJIB, 28.819 bita)
            langganan_admin.php      -> ke public_html     (45.415 bita, v3)
   [ ] 2. Buka https://rts.benedic-s.com/langganan_admin.php?diagnosa=1
          Bagian "PERIKSA BERKAS" harus menulis:
            api/langganan_inti.php : 28.819 bita (seharusnya 28.819 bita)
            Menu Langganan PRO pada sidebar : ADA (sidebar.php sudah diperbarui)
   [ ] 3. Buka https://rts.benedic-s.com/langganan_admin.php - halaman harus
          terbuka normal beserta kartu Pengaturan Harga & Durasi.
   [ ] 4. Uji aplikasi: keluar lalu masuk kembali pada aplikasi HP, untuk
          memastikan login tidak terpengaruh.

 Catatan cara mengunggah
   Gunakan cPanel - File Manager - Upload (pilih berkasnya), atau FileZilla.
   JANGAN menyalin-tempel isi berkas ke editor cPanel, sebab berkas panjang
   mudah terpotong dan hasilnya HTTP ERROR 500.
