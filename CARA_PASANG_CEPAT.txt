 LIMA PERUBAHAN PUTARAN 18J
 --------------------------
   1. PENYARING SALES DISTRICT DI MENU PRO.
      Pada halaman Pilih Toko (Kasir), Peta Customer, Radar Customer,
      Rute Plan, dan Program sekarang ada BARIS PENYARING SALES DISTRICT.
        - RTS & TF   : terkunci pada Sales District akunnya (baris biru).
        - WSS, SMST, ADMIN, ASS : dapat memilih SEMUA DISTRICT atau satu
          district; tombolnya dapat digeser ke samping dan memuat jumlah
          toko tiap district.
      Pilihan disimpan di HP dan dipakai bersama seluruh menu PRO.
   2. APLIKASI TIDAK BERAT LAGI.
      Karena hanya satu district yang dibaca, daftar dan peta biasanya
      memuat 200-500 toko (bukan 3000+). Bila Bapak memilih SEMUA DISTRICT,
      peta berhenti menggambar sesudah 1200 titik dan menampilkan pesan
      kuning yang meminta memilih district.
   3. SALINAN DI HP DIRAPIKAN (RTS & TF).
      Setiap SINKRONKAN SEKARANG, toko district lain yang masih tersimpan
      dari pemakaian sebelumnya otomatis dibuang.
   4. MENU PROGRAM.
        - Tombol PETA PENUH pada kotak "Peta & filter program" -> peta
          memakai SATU LAYAR penuh.
        - Lencana kuning "x BELUM KIRIM" pada baris customer DIHAPUS.
          Sebagai gantinya tampil HARI kunjungan, SALES DISTRICT, dan
          lencana hijau SUDAH DIKUNJUNGI bila toko sudah dikunjungi hari ini.
        - List customer dapat DIPILAH PER HARI (Semua hari, Senin ... Minggu)
          dan PER KUNJUNGAN (Semua / SUDAH / BELUM hari ini).
   5. PENANDA VERSI baru: RTS-2026-10-06-18J, pubspec 1.5.4+19.

 LANGKAH 1 - DI HOSTING (cPanel)
 -------------------------------
   TIDAK ADA yang perlu diunggah pada putaran ini.
   Bila tabel program belum pernah dibuat: buka phpMyAdmin -> database ->
   menu SQL -> tempel isi RTS_PANEL_PROGRAM.sql -> GO.

 LANGKAH 2 - DI KOMPUTER (proyek Flutter D:\Project\rts_panel_app)
 ----------------------------------------------------------------
   1. Ekstrak paket ini ke mana saja (misalnya Desktop), pilih TIMPA semua.
   2. Klik kanan  LANGKAH1_PASANG_SEMUA.ps1  ->  Run with PowerShell
      (skrip ini menimpa main.dart ke DUA tempat: akar folder dan lib\main.dart)
   3. Buka terminal di folder proyek, jalankan berurutan:
          flutter clean
          flutter pub get
          flutter analyze
          flutter build apk --release

 LANGKAH 3 - DI HP
 -----------------
   1. Pasang APK baru dengan cara MENIMPA. JANGAN hapus aplikasi lama.
   2. Buka aplikasi, lalu Menu Utama -> SINKRONISASI -> SINKRONKAN SEKARANG
      (butuh internet sekali supaya salinan toko di HP diperbarui).
   3. Buka MENU PRO -> PETA CUSTOMER. Pada baris Sales District tekan nama
      district yang ingin dilihat, atau SEMUA DISTRICT.
   4. Buka MENU PRO -> PROGRAM:
        - tekan ikon PETA di kanan atas -> tombol PETA PENUH
        - pada daftar customer, tekan pilihan HARI KUNJUNGAN dan KUNJUNGAN.

 PEMERIKSAAN SESUDAH PASANG
 --------------------------
   Di komputer: jalankan .\PERIKSA_KODE_APLIKASI.ps1
       bagian 6f harus menulis putaran 18J pada keenam berkas.
   Di aplikasi: Pengaturan harus menulis  RTS-2026-10-06-18J.

 KALAU BUILD GAGAL DENGAN PESAN "jenisAwal"
 -----------------------------------------
   lib\main.dart:2847:13: Error: No named parameter with the name 'jenisAwal'.

   Artinya lib\main.dart masih versi LAMA (tiga tombol Program), sedangkan
   lib\program.dart sudah versi baru. Perbaikannya:
      1. Pastikan paket 18J sudah diekstrak (TIMPA semua berkas).
      2. Jalankan LANGKAH1_PASANG_SEMUA.ps1 (menimpa main.dart di akar folder
         DAN lib\main.dart sekaligus).
      3. Jalankan PERIKSA_KODE_APLIKASI.ps1 -> bagian 6f harus [ADA] semua.
      4. flutter clean -> flutter pub get -> flutter run
